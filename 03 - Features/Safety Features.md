## Предупреждения и уведомления

### Ремень безопасности

```
Блок: KOMBI / CAS
Параметр: SEATBELT_WARNING → aktiv/nicht_aktiv
```

> [!WARNING] Не рекомендуется отключать

### Гудки при закрытии с заведённым двигателем

```
Блок: [соответствующий]
Параметр: HORN_ON_LOCK_WITH_ENGINE → nicht_aktiv
```

## Дополнительные ассистенты

```

```
