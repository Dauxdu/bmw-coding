## Звук и мультимедиа

### Спортивные индикаторы в стиле M

```
Блок: HU_*** / KOMBI
Параметр: DISPLAY_THEME → M_Sport
```

### Звук оповещения от Rolls-Royce / BMW i8

```
Блок: [соответствующий]
Параметр: CHIME_SOUND → RR_i8_Custom
```

> [!NOTE]
> Требует загрузки пользовательских звуковых файлов (не все ГУ поддерживают).

---

## Дополнительные настройки

### Отключение ограничения скорости в меню

```
Блок: [соответствующий]
Параметр: SPEED_LIMIT_DISPLAY → nicht_aktiv
```

### Активация "скрытых" спортивных функций

```
Блок: [зависит от модели]
Параметры:
- HIDDEN_SPORT_FUNCTIONS → aktiv
- PERFORMANCE_MENU → aktiv
```

> [!WARNING]
> Некоторые функции могут быть несовместимы с вашей комплектацией.
