## Климат и прочее

### Кнопка AUTO не включает кондиционер

```
Блок: [соответствующий]
Параметр: CLIMATE_AUTO_AC → nicht_aktiv
```

### Выключение музыки при открытии двери

```
Блок: HU_***
Параметр: MUTE_ON_DOOR_OPEN → aktiv
```

---

> [!TIP]
> Активируйте функции по мере необходимости. Не все опции совместимы друг с другом — тестируйте после каждого изменения.
