# Comfort Features

> [!IMPORTANT]
> **IHKA, FEM_BODY, HU_NBT** — сводный файл комфортных функций.

---

## Кнопка AUTO не включает кондиционер

### Настройка параметров для F-серии

```text
Блок: IHKA → 3002
Параметры:
- MEMORY_OFF → aktiv // Память состояния кондиционера (default: nicht_aktiv)
```

> [!NOTE]
> Кондиционер запоминает состояние «Вкл/Выкл» от предыдущей поездки.
> На некоторых автомобилях с `MEMORY_OFF → aktiv` кондиционер может
> всегда запускаться в состоянии «Выкл».

## Температура подогрева сидений

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3090
Параметры:
- TEMP_LEHNE_STUFE_1_FRONT → werte=96 // Спинка перед, уровень 1 (default: 95°F)
- TEMP_LEHNE_STUFE_2_FRONT → werte=A2 // Спинка перед, уровень 2 (default: 106°F)
- TEMP_LEHNE_STUFE_3_FRONT → werte=AE // Спинка перед, уровень 3 (default: 116°F)
- TEMP_SITZ_STUFE_1_FRONT → werte=94  // Сиденье перед, уровень 1 (default: 94°F)
- TEMP_SITZ_STUFE_2_FRONT → werte=A0  // Сиденье перед, уровень 2 (default: 104°F)
- TEMP_SITZ_STUFE_3_FRONT → werte=AC  // Сиденье перед, уровень 3 (default: 114°F)
- TEMP_LEHNE_STUFE_1_FOND → werte=96  // Спинка зад, уровень 1
- TEMP_LEHNE_STUFE_2_FOND → werte=A2  // Спинка зад, уровень 2
- TEMP_LEHNE_STUFE_3_FOND → werte=AE  // Спинка зад, уровень 3
- TEMP_SITZ_STUFE_1_FOND → werte=94   // Сиденье зад, уровень 1
- TEMP_SITZ_STUFE_2_FOND → werte=A0   // Сиденье зад, уровень 2
- TEMP_SITZ_STUFE_3_FOND → werte=AC   // Сиденье зад, уровень 3
```

### Формула расчёта значения

```text
HEX = (Температура_°C + 40) × 2
Пример: 41°C → (41 + 40) × 2 = 162 (dec) = A2 (hex)
```

## Easy Entry (лёгкий вход/выход)

### Настройка параметров для F-серии

```text
Блок: SM2 → 3000
Параметры:
- EINAUSSTIEGSHILFE → Modus_FA_SLV // Сиденье отъезжает при выключении зажигания
- MEMORY_GONG → aktiv              // Звуковой сигнал при сохранении памяти сидений
```

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка              | Как проверить настройку / Решение                      |
| :----------------------------- | :----------------------------------------------------- |
| Кондиционер всегда выключен    | Проверить MEMORY_OFF, поведение может варьироваться    |
| Подогрев не меняет температуру | Проверить наличие опции подогрева, значения в FEM_BODY |
| Easy Entry не работает         | Проверить наличие SM2, электропривод сидений           |

---

> [!WARNING]
> Изменение температуры подогрева сидений влияет на комфорт и
> безопасность. Не устанавливайте значения выше AE (116°F / 47°C).
