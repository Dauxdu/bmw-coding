# Windows & Doors

> [!IMPORTANT]
> **FEM_BODY, REM, FRM, BDC_BODY** — F20/F30 → FEM_BODY + REM;
> F01/F10 → FRM; G-series → BDC_BODY.

---

## Работа стёкол при открытой двери

### Настройка параметров для F-серии (F20, F30, F34)

```text
Блок: FEM_BODY → 3050
Параметры:
- FH_TUERAUF_STOP_MAUT → nicht_aktiv // Передние стёкла работают при открытой двери

Блок: REM → 3050
Параметры:
- FH_TUERAUF_STOP_MAUT → nicht_aktiv // Задние стёкла работают при открытой двери
```

### Настройка параметров для F-серии (F01, F10, F25)

```text
Блок: FRM → 3050
Параметры:
- FH_TUER_AUF_STOP_MAUT → nicht_aktiv // Стёкла работают при открытой двери
```

### Настройка параметров для G-серии

```text
Блок: BDC_BODY → 44ED
Параметры:
- FH_TUERAUF_STOP_MAUT → nicht_aktiv // Стёкла работают при открытой двери
```

> [!NOTE]
> Стеклоподъёмники продолжают работать при открытой двери водителя
> или пассажира. Удобно для проветривания и мойки.

## Комфортное открытие/закрытие стёкол с ключа

### Настройка параметров для F-серии (F20, F30, F34)

```text
Блок: FEM_BODY → 3053
Параметры:
- KOMFORTOEFFNUNG_FB → aktiv       // Открытие стёкол долгим нажатием «Открыть» на ключе
- KOMFORTSCHLIESSUNG_FB → aktiv    // Закрытие стёкол долгим нажатием «Закрыть» на ключе
- KOMFORT_OEFFNEN → werte=0A       // Задержка комфортного открытия (HEX, 0A = 1 сек)
- KOMFORT_SCHLIESSEN → werte=00    // Задержка комфортного закрытия (00 = без задержки)
- KOMFORT_OEFF_HINTEN → werte=05   // Задержка между передними и задними стёклами
- KOMFORT_SCHL_VORNE → werte=05    // Задержка между передними стёклами при закрытии
- KOMFORT_OEFF_SHD → werte=23      // Задержка между стёклами и люком (при наличии)
- KOMFORT_SCHL_SHD → werte=23      // Задержка между стёклами и люком при закрытии
```

### Таблица значений задержек

| Задержка          | HEX | Секунды |
| :---------------- | :-- | :------ |
| Без задержки      | 00  | 0       |
| Короткая          | 05  | ~0.5    |
| Средняя           | 0A  | ~1      |
| Длинная (default) | 0F  | ~1.5    |

## Разблокировка дверей при выключении зажигания

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3040
Параметры:
- CLM_UNLOCK_KL15OFF_AFTER_PIA_AUTO_LOCK → aktiv // Двери разблокируются при выкл. зажигании
```

> [!NOTE]
> Если включена автоблокировка дверей, при выключении зажигания все
> двери автоматически разблокируются.

---

## Автоблокировка дверей

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3040
Параметры:
- CLM_TIME_PIA_LOCK_AT_TIMEOUT → werte=0C // Автоблокировка через 120 сек (HEX, ед. = 10 сек)
```

---

## Выключение радио при открытии двери

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3020
Параметры:
- TCM_LOGIC_R_OFF_DOOR → aktiv // Радио и навигация выключаются при открытии двери водителя
```

## Количество миганий поворотников при блокировке/разблокировке

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3060
Параметры:
- QUITTBLK_SICHERN_ANZAHL → werte=X-1      // Мигания при блокировке (default: 01 = 2 мигания)
- QUITTBLK_ENTSCHAERFEN_ANZAHL → werte=X-1 // Мигания при разблокировке (default: 02 = 3 мигания)
```

---

## Задержка открытия багажника через Comfort Access

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3040
Параметры:
- CLM_TIMEOUT_HK_SMO → wert_01      // Минимальная задержка открытия багажника (HEX × 0.1 сек)
- CLM_SMO_INDICATOR → nicht_aktiv   // Отключить мигание задних фонарей при открытии багажника
```

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка            | Как проверить настройку / Решение                                                      |
| :--------------------------- | :------------------------------------------------------------------------------------- |
| Стекло не поднимается        | Инициализировать стеклоподъёмник: поднять → удержать 3 сек → опустить → удержать 3 сек |
| Двери не блокируются         | Проверить CLM_TIME_PIA_LOCK_AT_TIMEOUT, предохранители                                 |
| Комфорт-закрытие не работает | Проверить KOMFORTSCHLIESSUNG_FB, выполнить цикл зажигания                              |

---

> [!WARNING]
> После отключения АКБ или замены блока FEM_BODY/REM необходимо
> выполнить инициализацию стеклоподъёмников (полный цикл вверх/вниз
> с удержанием кнопки 3 секунды в каждом положении).
