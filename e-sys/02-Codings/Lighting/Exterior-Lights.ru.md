# Exterior Lights (Стоп-сигналы и автосвет)

> [!IMPORTANT]
> **FEM_BODY** — F-series → FEM_BODY.

---

## Мигающие стоп-сигналы при экстренном торможении

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3060
Параметры:
- ESS_AKTIVIERBARER_AUSGANG → bremslicht_blinkend // Стоп-сигналы мигают (default: flaechenvergroesserung)
- ESS_AKTIVIERUNG_GESCHW → user                   // Порог скорости активации (HEX, default: 02)
```

### Таблица значений ESS_AKTIVIERBARER_AUSGANG

| Поведение                              | Значение               |
| :------------------------------------- | :--------------------- |
| Загорается внутренняя секция (default) | flaechenvergroesserung |
| Стоп-сигналы мигают                    | bremslicht_blinkend    |

> [!NOTE]
> В некоторых версиях CAFD параметры называются `ESS_ERSSCHEINUNGSBILD`
> и `ESS_ON_VERZ` (порог замедления).

---

## Аварийка при экстренном торможении

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3060
Параметры:
- WB_GB_ENABLE → nicht_aktiv // Аварийка НЕ включается после экстренного торможения (default: aktiv)
```

> [!WARNING]
> Автоматическая аварийка предупреждает едущих сзади. Отключайте
> осознанно.

---

## Чувствительность автоматического включения фар

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3130
Параметры:
- RLS_DEF_FLC_SCHWELLWERT_SATZ → unempfindlich // Порог датчика света (default: normal)
```

### Таблица значений

| Чувствительность      | Значение         |
| :-------------------- | :--------------- |
| Очень чувствительный  | sehr_empfindlich |
| Чувствительный        | empfindlich      |
| Стандартный (default) | normal           |
| Нечувствительный      | unempfindlich    |
| Режим ДХО             | Tagfahrlicht     |

> [!NOTE]
> «Чувствительный» — фары включаются раньше (при большей освещённости).

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка            | Как проверить настройку / Решение                        |
| :--------------------------- | :------------------------------------------------------- |
| Стоп-сигналы не мигают       | Проверить имя параметра (ESS\_\* зависит от версии CAFD) |
| Фары включаются слишком рано | Выбрать unempfindlich в RLS_DEF_FLC_SCHWELLWERT_SATZ     |
| Ошибка в блоке               | Восстановить резервную копию кодировки FEM_BODY          |

---
