# LDW (Lane Departure Warning)

> [!IMPORTANT]
> **KAFAS2, KAFAS, KOMBI** — F-series → KAFAS2; G-series → KAFAS.

---

## Изменение скорости срабатывания LDW

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3020
Параметры:
- THRV_AVAI_TLC_HIGH → 3C // Верхний порог скорости LDW (3C = 60 км/ч)
- THRV_AVAI_TLC_LOW → 37  // Нижний порог скорости LDW (37 = 55 км/ч)
```

> [!NOTE]
> Заводские значения зависят от рынка.

### Настройка параметров для G-серии

```text
Блок: KAFAS → 3103
Параметры:
- LDW_C_THRESHOLD_VELOCITY_AVAILABILITY_HIGH → user // Верхний порог (HEX, км/ч)
- LDW_C_THRESHOLD_VELOCITY_AVAILABILITY_LOW → user  // Нижний порог (HEX, км/ч)
```

### Таблица значений скорости

| HEX | км/ч |
| :-- | :--- |
| 28  | 40   |
| 32  | 50   |
| 37  | 55   |
| 3C  | 60   |
| 46  | 70   |
| 50  | 80   |

---

## Включение/отключение LDW

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3020
Параметры:
- TLC_ON_OFF → TLC_on_F020_F030_F025 // Включение LDW
```

> [!NOTE]
> Параметры KOMBI нужны только при дооснащении LDW. Если LDW есть
> с завода, они уже включены.

---

## Распознавание обочины и бордюра

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3000
Параметры:
- ROAD_EDGE_WARNING_ENABLED → 01 // Обочина + бордюр в LDW (default: road_edge_detection_disabled = 00)
- ROAD_EDGE_DISTANCE_SHIFT       // Смещение порога до края дороги (default: value_1 = 00 00 00 64)
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка   | Как проверить настройку / Решение                |
| :------------------ | :----------------------------------------------- |
| LDW не срабатывает  | Проверить скорость, TLC_ON_OFF, чистоту камеры   |
| Ложные срабатывания | Увеличить пороги скорости, проверить разметку    |
| Ошибка в KAFAS      | Выполнить калибровку камеры, проверить крепление |

---

> [!WARNING]
> На F30 с завода `TLC_ON_OFF = 01` (включено). Если там `00`, система
> будет полностью неактивна. После калибровки камеры параметры
> могут сброситься.
