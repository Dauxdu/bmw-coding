# Codecs & USB Video

> [!IMPORTANT]
> **HU_NBT** — основное головное устройство с поддержкой USB-видео.

---

## Включение поддержки кодеков

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3000
Параметры:
- ENT_CODEC_OGG → aktiv        // Кодек OGG
- ENT_CODEC_XVID → aktiv       // Кодек XVID
- ENT_CODEC_XVCD → aktiv       // Кодек XVCD
- ENT_CODEC_VCD → aktiv        // Кодек VCD
- ENT_MC_VIDEO_SUPPORT → aktiv // MC Video поддержка
- ENT_VIDEO_HMI → aktiv        // Кнопка «DVD Menu» при просмотре DVD

Блок: HU_NBT → 3003
Параметры:
- API_USB_VIDEO → both // USB Video (front + rear, default: none)
```

> [!NOTE]
> Поддерживаемые форматы: AVI, MP4, MKV (с кодеками Xvid, DivX),
> OGG видео, видео с субтитрами (ограниченно).

---

## Требования к файлам

```text
Рекомендуемые параметры:
- Разрешение: до 1920×1080 (Full HD)
- Битрейт: до 10–15 Мбит/с
- Файловая система: FAT32 или exFAT
- Имя файла: латиница, без спецсимволов

Не поддерживается:
- HEVC / H.265
- 4K видео
- Файлы > 32 ГБ (ограничение FAT32)
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка          | Как проверить настройку / Решение               |
| :------------------------- | :---------------------------------------------- |
| Видео не воспроизводится   | Проверить кодек, разрешение, имя файла          |
| Звук есть, изображения нет | Проверить видео-кодек (XVID/OGG), обновить файл |
| Флешка не определяется     | Форматировать в FAT32, проверить порт USB       |

---

> [!WARNING]
> Для гарантированной совместимости конвертируйте видео в:
> контейнер MP4/AVI, видео Xvid/H.264, аудио MP3/AAC,
> разрешение 1280×720 или 1920×1080.
