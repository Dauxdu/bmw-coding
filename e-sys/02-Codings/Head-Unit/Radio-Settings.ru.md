# Radio Settings

> [!IMPORTANT]
> **HU_NBT, HU_CIC** — в зависимости от поколения головного устройства.

---

## Настройка региона радиоприёмника

### Настройка параметров для F-серии

```text
Блок: HU_NBT
Параметры:
- RADIO_COUNTRY → ece // Регион: Европа/РФ (варианты: ece, usa, jpn, kor)
```

---

## Частотная характеристика FM

### Настройка параметров для F-серии

```text
Блок: HU_NBT
Параметры:
- FM_DEEMPHASIS → 50us // Стандарт для Европы и России (75us = США)
```

---

## Отображение частоты в МГц

### Настройка параметров для F-серии

```text
Блок: HU_NBT
Параметры:
- ANZEIGE_FREQ → nicht_aktiv // Частота в МГц (101.2) вместо кГц (10120)
```

---

## Погодный диапазон (HU_CIC, США)

### Настройка параметров для F-серии

```text
Блок: HU_CIC → 3002
Параметры:
- RADIO_WEATHERBAND → aktiv // NOAA Weatherband в источниках радио
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка                | Как проверить настройку / Решение   |
| :------------------------------- | :---------------------------------- |
| Плохой приём радиостанций        | Проверить антенну, RADIO_COUNTRY    |
| Искажённый звук                  | Установить FM_DEEMPHASIS → 50us     |
| Не отображается название станции | Проверить сигнал радиостанции (RDS) |

---

> [!WARNING]
> Изменение региона может повлиять на доступные частотные диапазоны
> и функциональность RDS. Сохраните исходные значения перед изменением.
