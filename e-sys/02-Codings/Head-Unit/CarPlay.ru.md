# CarPlay

> [!IMPORTANT]
> **HU_NBT, HU_NBT_EVO, HU_MGU** — в зависимости от поколения ГУ.
> Требуется поддержка на уровне железа (WiFi-модуль для беспроводного).

---

## Базовая активация CarPlay

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3000
Параметры:
- CARPLAY → aktiv // Активация Apple CarPlay
```

### Настройка параметров для G-серии

```text
Блок: HU_MGU → 3000
Параметры:
- CARPLAY → aktiv      // Активация Apple CarPlay
- WIFI_HOTSPOT → aktiv // Беспроводной CarPlay (требует WiFi-модуль)
```

> [!NOTE]
> Проводной CarPlay: требует только активации параметра.
> Беспроводной: требует наличия WiFi-модуля и активации WIFI_HOTSPOT.
> iPhone с iOS 13+.

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка        | Как проверить настройку / Решение                          |
| :----------------------- | :--------------------------------------------------------- |
| CarPlay не подключается  | Проверить кабель, параметр CARPLAY, версию iOS             |
| Беспроводной не работает | Убедиться в наличии WiFi-модуля, активировать WIFI_HOTSPOT |
| Нет звука / прерывания   | Перезагрузить ГУ и телефон, проверить кабель               |
