# Codecs & USB Video

> [!IMPORTANT]
> **HU_NBT** — основное головное устройство с поддержкой кодирования

---

## Включение поддержки кодеков для видео с USB

```
Блок: HU_NBT → 3000
Параметры:
- ENT_CODEC_OGG → aktiv
- ENT_CODEC_XVID → aktiv
- ENT_CODEC_VCD → aktiv
- ENT_MC_VIDEO_SUPPORT → aktiv

Блок: HU_NBT → 3003
Параметр: API_USB_VIDEO → both
```

> [!NOTE]
>
> - AVI, MP4, MKV (с кодеками Xvid, DivX)
> - OGG видео
> - Видео с субтитрами (ограниченно)

---

## Требования к файлам

```
Рекомендуемые параметры:
- Разрешение: до 1920×1080 (Full HD)
- Битрейт: до 10-15 Мбит/с
- Файловая система: FAT32 или exFAT
- Имя файла: латиница, без спецсимволов

Не поддерживается:
- HEVC / H.265 (без дополнительной активации)
- 4K видео
- Файлы >32 ГБ (ограничение FAT32)
```

---

## Оптимизация воспроизведения

### Увеличение буфера воспроизведения

```
Блок: HU_NBT
Параметр: USB_VIDEO_BUFFER_SIZE → увеличить значение
```

### Автозапуск последнего видео

```
Блок: HU_NBT
Параметр: USB_VIDEO_RESUME → aktiv
```

---

## Troubleshooting

| Проблема                   | Решение                                                |
| -------------------------- | ------------------------------------------------------ |
| Видео не воспроизводится   | Проверить кодек, разрешение, имя файла                 |
| Звук есть, изображения нет | Проверить видео-кодек, обновить файл                   |
| Флешка не определяется     | Форматировать в FAT32, проверить порт USB              |
| Ошибка в блоке             | Сбросить настройки медиа, проверить версию прошивки ГУ |

---

> [!TIP]
> Для гарантированной совместимости конвертируйте видео в:
>
> - Контейнер: MP4 или AVI
> - Видео: Xvid или H.264
> - Аудио: MP3 или AAC
> - Разрешение: 1280×720 или 1920×1080
