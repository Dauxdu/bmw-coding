# Radio Settings

> [!IMPORTANT]
> **HU_NBT**, **HU_CIC**, **HU_ENTRYEVO** — в зависимости от поколения

---

## Настройка региона радиоприёмника

```
Блок: HU_NBT
Параметр: RADIO_COUNTRY → ece
```

> [!NOTE] Доступные значения
>
> - `ece` — Европа (рекомендуется для РФ/СНГ)
> - `usa` — Северная Америка
> - `jpn` — Япония
> - `kor` — Корея

---

## Настройка частотной характеристики (FM)

```
Блок: HU_NBT
Параметр: FM_DEEMPHASIS → 50us
```

> [!NOTE]
>
> - 50us — стандарт для Европы и России
> - 75us — стандарт для США

---

## Отображение частоты в МГц

```
Блок: HU_NBT
Параметр: ANZEIGE_FREQ → nicht_aktiv
```

> [!NOTE]
> Частота отображается в привычном формате (например, 101.2 МГц вместо 10120 кГц).

---

## Дополнительные настройки радио

### Автопоиск сильных станций

```
Блок: [соответствующий]
Параметр: RADIO_STRONG_SIGNAL_PRIORITY → aktiv
```

### Сохранение региональных пресетов

```
Блок: [соответствующий]
Параметр: RADIO_REGIONAL_PRESETS → aktiv
```

### Отображение названия станции (RDS)

```
Блок: [соответствующий]
Параметр: RADIO_RDS_DISPLAY → aktiv
```

---

## Troubleshooting

| Проблема                         | Решение                                        |
| -------------------------------- | ---------------------------------------------- |
| Плохой приём радиостанций        | Проверить антенну, параметр RADIO_COUNTRY      |
| Искажённый звук                  | Установить FM_DEEMPHASIS → 50us                |
| Не отображается название станции | Проверить RDS-настройки, сигнал радиостанции   |
| Ошибка в блоке                   | Сбросить настройки радио, обновить прошивку ГУ |
