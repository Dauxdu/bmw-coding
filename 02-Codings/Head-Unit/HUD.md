# HUD (Head-Up Display)

> [!IMPORTANT]
> **HUD**, **HU_NBT**, **KOMBI** — в зависимости от функции

![[head_unit.png]]

---

## Индикация поворотников в проекционном дисплее

> [!WARNING]
> Работает только на дисплеях 6WA (на 6WB не работает)

```
Блок: HU_NBT → 3001
Параметр: HUD_TURNSIGNAL → aktiv

Блок: KOMBI → 3008
Параметр: HUD_PIA_BLINKER → aktiv

Блок: KOMBI → 3000
Параметр: BLINKER_HUD_ENABLE → aktiv
```

### Активация в меню

После кодирования в NBT появится пункт:

```
Настройки → Проекционный дисплей → Индикация поворотников [Вкл/Выкл]
```

---

## Настройка яркости и положения

```
Блок: HUD
Параметры:
- BRIGHTNESS_AUTO → aktiv
- POSITION_HEIGHT → настроить значение
- POSITION_TILT → настроить значение
```

---

## Отображаемая информация

```
Блок: HUD / KOMBI
Параметры:
- HUD_SPEED_DISPLAY → aktiv
- HUD_NAVIGATION_ARROWS → aktiv
- HUD_ASSISTANT_INFO → aktiv
- HUD_MEDIA_INFO → nicht_aktiv (по желанию)
```

---

## Стиль отображения

```
Блок: HUD
Параметр: DISPLAY_STYLE → M_Sport || Classic || Minimal
```

> [!NOTE]
> Зависит от версии прошивки и комплектации. Не все стили доступны на всех авто.

---

## Отключение предупреждений в HUD

```
Блок: HUD
Параметры:
- HUD_WARNING_MESSAGES → nicht_aktiv
- HUD_PARKING_ALERTS → nicht_aktiv
```

---

## Troubleshooting

| Проблема                          | Решение                                                      |
| --------------------------------- | ------------------------------------------------------------ |
| Поворотники не отображаются в HUD | Проверить все три параметра, убедиться в наличии дисплея 6WA |
| HUD не включается                 | Проверить питание, параметры активации, версию прошивки      |
| Изображение размыто               | Откалибровать положение и фокус через сервисное меню         |
| Ошибка в блоке                    | Сбросить адаптации, проверить совместимость версий           |

---

> [!TIP]
> Для точной настройки положения изображения:
>
> 1. Сесть в водительское кресло в обычной позе
> 2. Через сервисное меню отрегулировать высоту и угол
> 3. Сохранить настройки для текущего ключа
