# iDrive Features

> [!IMPORTANT]
> **HU_NBT, HU_CIC, CMB_MEDIA** — в зависимости от поколения ГУ.
> Не все параметры HU_CIC работают на HU_NBT и наоборот.

---

## Температура и давление шин в iDrive

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3001
Параметры:
- RDC_DRUCK_TEMP → druck_und_temperatur // Температура + давление шин (default: druck)
```

> [!NOTE]
> Требует датчиков давления с поддержкой температуры (опция 2VB).

---

## Голосовое управление

### Настройка параметров для F-серии

```text
Блок: CMB_MEDIA → 3000
Параметры:
- SYS_EIN_AUS → aktiv // Базовое голосовое распознавание

Блок: HU_NBT → 3003
Параметры:
- CE_DEVICE_SPEECH_RECONGNITION → aktiv // Siri Eyes-Free (удержание кнопки голоса)
```

---

## Маршрут и навигация

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3000
Параметры:
- ROUTE_FLIGHT → aktiv               // Симулятор маршрута «Route preview» — Part 1
- NAVI_SCROLLING_ALONG_ROUTE → aktiv // Симулятор маршрута — Part 2
- NAVI_ROAD_PREVIEW → aktiv          // «Route Info» (список манёвров)
- NAVI_AUTOZOOM → aktiv              // Авто-зум при приближении к повороту

Блок: HU_NBT → 3001
Параметры:
- NAVI_TRIP_IMPORT → aktiv // Импорт маршрута через USB
```

---

## Отображение SMS целиком

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3003
Параметры:
- PIM_Driving_Text → Whole_text // Полное сообщение SMS (default: up_to_three_lines)
```

---

## Рингтон и Inband Ringing

### Настройка параметров для F-серии

```text
Блок: CMB_MEDIA → 3001
Параметры:
- INBAND_RINGING → aktiv   // Рингтон с телефона (работает на iPhone, не на Android)
- RINGTONE → ring_tone2    // Выбор рингтона (если Inband Ringing выключен)
```

---

## Максимальная громкость при запуске

### Настройка параметров для F-серии (HU_CIC)

```text
Блок: HU_CIC → 3002
Параметры:
- VOL_MAX_ON → 32 // Громкость до 100% при запуске (default: 19 = 25%)
```

---

## Меню разработчика

### Настройка параметров для F-серии (HU_CIC)

```text
Блок: HU_CIC → 3000
Параметры:
- ENTWICKLER_MENUE → aktiv // Меню разработчика в настройках (Build/Date/Versions)
```

## История сервисного обслуживания

### Настройка параметров для F-серии

```text
Блок: HU_NBT / HU_CIC → 3000
Параметры:
- SERVICE_HISTORY → aktiv // История ТО у дилера в iDrive (default: nicht_aktiv)
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка                | Как проверить настройку / Решение              |
| :------------------------------- | :--------------------------------------------- |
| Температура шин не отображается  | Проверить RDC_DRUCK_TEMP, наличие датчиков 2VB |
| Голосовое управление не работает | Проверить SYS_EIN_AUS, наличие микрофона       |
| Маршрут не импортируется         | Проверить NAVI_TRIP_IMPORT, формат файла       |

---

> [!WARNING]
> Не все параметры HU_CIC совместимы с HU_NBT. Проверяйте тип
> головного устройства перед кодированием.
