# Trunk (HKL)

> [!INFO] Блок управления
> **HKL** — Heckklappen (багажник), **HKFM** — модуль привода

---

## Плавное открытие багажника (без удара)

**Модели:** F20, F30, F34, F01, F10...

```
Блок: HKFM
Параметр: DREHZAL_SEGMENT_OEFF
Значение: 50 58 58 58 58 58 58 58 45
```

> [!TIP] Эффект
> Багажник открывается плавно, без резкого удара в крайнем положении.

---

## Плавное закрытие багажника (без удара)

**Модели:** F20, F30, F34, F01, F10...

```
Блок: HKFM
Параметр: DREHZAL_SEGMENT_SCHL
Значение: 20 30 58 58 58 58 58 58 45
```

> [!TIP] Эффект
> Закрытие происходит мягко, механизм не бьёт в замок.

---

## Закрытие багажника с кнопки в салоне

**Модели:** F20, F30, F34...

```
Блок: HKFM
Параметры:
- SCH_FBD → aktiv
- SCH_TOEHKI → aktiv
- TASTER_FBD → aktiv
```

> [!NOTE] Требует
> Установленной кнопки закрытия багажника в салоне.

---

## Уменьшение задержки открытия с ключа

```
Блок: FEM BODY / 30D0 RemoteControl
Параметр: RC_TIME_DELAY_BOOTLID
Значение: установить минимальное (lower Werte)
```

---

## Закрытие багажника без задержки

```
Блок: HKL
Параметры:
- HKL_ROCKERSWITCHPOS2_LONGPRESS_CLOSE → 00
- HKL_ROCKERSWITCHPOS2_DELAY_CLOSE → 00, 00
- HKL_REMOTECONTROLLIFTGATEBUTTON_LONGPRESS_CLOSE → 00
- HKL_REMOTECONTROLLIFTGATEBUTTON_DELAY_CLOSE → 00, 00
```

---

## Комфортное управление с ключа

### Открытие & закрытие долгим нажатием

```
Блок: HKL
Параметры:
- KOMFORT_OEFFNEN_HKL → aktiv
- KOMFORT_SCHLIESSEN_HKL → aktiv
```

### Закрытие одним нажатием кнопки на ключе

```
Блок: HKL
Параметр: FUNKTION_FBD_SCHLIESSEN_2 → aktiv
```

### Закрытие с кнопки в ногах водителя

```
Блок: HKL
Параметр: FUNKTION_TOEHKI → aktiv
```

---

## Troubleshooting

| Проблема                      | Решение                                        |
| ----------------------------- | ---------------------------------------------- |
| Не работает плавное закрытие  | Проверить калибровку HKL, выполнить адаптацию  |
| Кнопка в салоне не реагирует  | Проверить кодировку, наличие физической кнопки |
| Задержка при открытии с ключа | Уменьшить RC_TIME_DELAY_BOOTLID                |

---

> [!WARNING] Важно
> После изменений в HKL выполнить адаптацию механизма багажника через сервисные функции.
