# Trunk (HKL / HKFM)

> [!IMPORTANT]
> **HKFM, HKL, FEM_BODY** — HKFM = модуль привода багажника;
> HKL = контроллер крышки; FEM_BODY = задержки Comfort Access.

---

## Плавное открытие багажника (без удара)

### Настройка параметров для F-серии

```text
Блок: HKFM → 3010
Параметры:
- DREHZAL_SEGMENT_OEFF → 50 58 58 58 58 58 58 58 45 // Плавное открытие без удара
```

---

## Плавное закрытие багажника (без удара)

### Настройка параметров для F-серии

```text
Блок: HKFM → 3010
Параметры:
- DREHZAL_SEGMENT_SCHL → 20 30 58 58 58 58 58 58 45 // Плавное закрытие без удара
```

> [!NOTE]
> Массив из 9 байт задаёт профиль скорости привода на каждом сегменте
> хода. Изменение первых байт влияет на начальный/конечный участок.

---

## Закрытие багажника с кнопки в салоне и с ключа

### Настройка параметров для F-серии

```text
Блок: HKFM → 3010
Параметры:
- SCH_FBD → aktiv      // Закрытие багажника кнопкой на ключе
- SCH_TOEHKI → aktiv   // Закрытие багажника кнопкой в салоне (ноги водителя)
- TASTER_FBD → aktiv   // Обязательный параметр для работы SCH_FBD и SCH_TOEHKI
```

> [!NOTE]
> Параметр `TASTER_FBD` является обязательным. Без него `SCH_FBD`
> и `SCH_TOEHKI` не активируются.

## Закрытие багажника без задержки (кнопка салона / ключ)

### Настройка параметров для F-серии

```text
Блок: HKL → 3010
Параметры:
- HKL_ROCKERSWITCHPOS2_LONGPRESS_CLOSE → 00            // Без удержания (кнопка салона)
- HKL_ROCKERSWITCHPOS2_DELAY_CLOSE → 00, 00            // Без задержки (кнопка салона)
- HKL_REMOTECONTROLLIFTGATEBUTTON_LONGPRESS_CLOSE → 00 // Без удержания (ключ)
- HKL_REMOTECONTROLLIFTGATEBUTTON_DELAY_CLOSE → 00, 00 // Без задержки (ключ)
```

---

## Комфортное управление с ключа

### Настройка параметров для F-серии

```text
Блок: HKL → 3010
Параметры:
- KOMFORT_OEFFNEN_HKL → aktiv       // Открытие долгим нажатием «Открыть» на ключе
- KOMFORT_SCHLIESSEN_HKL → aktiv    // Закрытие долгим нажатием «Закрыть» на ключе
- FUNKTION_FBD_SCHLIESSEN_2 → aktiv // Закрытие одним нажатием кнопки на ключе
- FUNKTION_TOEHKI → aktiv           // Закрытие кнопкой в ногах водителя
```

---

## Уменьшение задержки открытия с ключа

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 30D0
Параметры:
- RC_TIME_DELAY_BOOTLID → lower Werte // Уменьшение задержки открытия багажника с ключа
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка             | Как проверить настройку / Решение                            |
| :---------------------------- | :----------------------------------------------------------- |
| Не работает плавное закрытие  | Проверить калибровку HKL, выполнить адаптацию привода        |
| Кнопка в салоне не реагирует  | Проверить SCH_TOEHKI + TASTER_FBD, наличие физической кнопки |
| Задержка при открытии с ключа | Уменьшить RC_TIME_DELAY_BOOTLID в FEM_BODY                   |

---

> [!WARNING]
> После изменений в HKFM/HKL выполнить адаптацию механизма багажника
> через сервисные функции E-Sys (Service Functions → HKL → Adaptation).
