# Start-Stop (MSA)

> [!IMPORTANT]
> **CAS, FEM_BODY, BDC_BODY, DME/DDE** — в зависимости от серии
> автомобиля. F01/F10 → CAS; F20/F30 → FEM_BODY; G-series → DME/DDE.

---

## Запоминание последней настройки Start-Stop

### Настройка параметров для F-серии (F01, F10, F25)

```text
Блок: CAS → 3000
Параметры:
- TCM_MSA_MEMORY → aktiv // Память последнего состояния кнопки MSA
```

### Настройка параметров для F-серии (F20, F30, F34)

```text
Блок: FEM_BODY → 3023
Параметры:
- TCM_MSA_MEMORY → aktiv // Память последнего состояния кнопки MSA
```

### Настройка параметров для G-серии

```text
Блок: DME/DDE → 3000
Параметры:
- TCM_MSA_MEMORY → verbaut // Память последнего состояния (двигатель ВЫКЛ, зажигание ВКЛ)
```

> [!NOTE]
> Система запоминает последнее состояние кнопки Start-Stop и
> восстанавливает его при следующем запуске двигателя.

## Start-Stop выключен по умолчанию

### Настройка параметров для F-серии (F01, F10, F25)

```text
Блок: CAS → 3000
Параметры:
- TC_MSA_DEFAULT_OFF → aktiv // MSA выключена при каждом запуске
```

### Настройка параметров для F-серии (F20, F30, F34)

```text
Блок: FEM_BODY → 3023
Параметры:
- TCM_MSA_DEFAULT_OFF → aktiv // MSA выключена при каждом запуске
```

### Настройка параметров для G-серии

```text
Блок: DME/DDE → 3000
Параметры:
- TC_MSA_DEFAULT_OFF → verbaut // MSA выключена при каждом запуске
```

### Таблица значений

| Состояние               | Значение      |
| :---------------------- | :------------ |
| По умолчанию (F-series) | nicht_aktiv   |
| По умолчанию (G-series) | nicht_verbaut |
| Изменённое (F-series)   | aktiv         |
| Изменённое (G-series)   | verbaut       |

## Eco Pro не включает Start-Stop

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3023
Параметры:
- ECO_CONF_MSA → nicht_aktiv // Режим Eco Pro не активирует MSA
```

### Настройка параметров для G-серии

```text
Блок: HU_MGU → 3008
Параметры:
- FES_ECO_CONF_MSA → nicht_aktiv // Режим Eco Pro не активирует MSA
```

---

## Отключение уведомления MSA на приборной панели

### Настройка параметров для F-серии

```text
Блок: KOMBI → 3000
Параметры:
- MSA_VERFUEGBARANZEIGE_ENABLE → nicht_aktiv // Убрать «Auto Start-Stop Off» на KOMBI
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка                 | Как проверить настройку / Решение                      |
| :-------------------------------- | :----------------------------------------------------- |
| Настройка не сохраняется          | Проверить TCM_MSA_MEMORY, обновить прошивку блока      |
| MSA работает некорректно          | Проверить состояние АКБ, датчиков, выполнить адаптацию |
| Ошибка после кодирования G-series | Убедиться: двигатель ВЫКЛ, зажигание ВКЛ               |

---

> [!WARNING]
> Для G-серии прошивка DME/DDE выполняется строго при **выключенном
> двигателе** с **включённым зажиганием**. Нарушение порядка может
> повредить блок управления двигателем.
