# Mirrors

> [!IMPORTANT]
> **FEM_BODY, BDC_BODY** — F-series → FEM_BODY; G-series → BDC_BODY.

---

## Складывание/раскладывание зеркал с ключа

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3110
Параметры:
- ASP_AUSKLAPPEN_NACH_KOMFORTSCHLIESSEN → aktiv // Разложить зеркала при разблокировке
- ASP_BEIKLAPPEN_BEI_KOMFORTSCHLIESSEN → aktiv  // Сложить зеркала при закрытии
- ASP_GESCHWINDIGKEIT_AUTO_AUSKLAPPEN → 14      // Авто-раскладывание при 20 км/ч (HEX)
- ASP_MAX_GESCHWINDIGKEIT_BEIKLAPPEN → FF       // Макс. скорость складывания (FF = 255 км/ч)
```

### Таблица значений скорости

| Скорость          | HEX |
| :---------------- | :-- |
| 20 км/ч           | 14  |
| 40 км/ч (default) | 28  |
| Без ограничения   | FF  |

> [!NOTE]
> `ASP_MAX_GESCHWINDIGKEIT_BEIKLAPPEN` должно быть ≥ значения
> `ASP_GESCHWINDIGKEIT_AUTO_AUSKLAPPEN`. Зеркала складываются при
> удержании кнопки «Закрыть» на ключе и раскладываются при
> разблокировке или достижении заданной скорости.

## Парковочный наклон правого зеркала (G-series)

### Настройка параметров для G-серии

```text
Блок: BDC_BODY → 3110
Параметры:
- ASP_BORDSTEINAUTOMATIK_DELTA → 5A // Угол наклона правого зеркала при задней передаче
```

### Таблица значений угла

| Угол наклона  | Значение (HEX) |
| :------------ | :------------- |
| 90° (default) | 5A             |
| 80°           | 50             |
| 70°           | 46             |
| 59°           | 3B             |

> [!NOTE]
> При включении задней передачи правое зеркало наклоняется вниз для
> обзора бордюра. Возвращается в исходное положение при скорости
>
> > 15–20 км/ч или переключении в D/P.

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка         | Как проверить настройку / Решение                                      |
| :------------------------ | :--------------------------------------------------------------------- |
| Зеркало не наклоняется    | Проверить ASP_BORDSTEINAUTOMATIK_DELTA, выполнить адаптацию зеркал     |
| Зеркала не складываются   | Проверить ASP_BEIKLAPPEN_BEI_KOMFORTSCHLIESSEN, наличие электропривода |
| Зеркала не раскладываются | Проверить ASP_GESCHWINDIGKEIT_AUTO_AUSKLAPPEN                          |

---

> [!WARNING]
> После изменений в параметрах зеркал рекомендуется выполнить
> калибровку через сервисное меню или диагностический сканер.
