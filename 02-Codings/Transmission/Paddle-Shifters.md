# Paddle Shifters (Лепестки КПП)

> [!INFO] Блоки управления
> **FEM**, **EGS**, **SZL** — в зависимости от комплектации

---

## Активация переключения лепестками

**Модели:** F20, F30, F34...

```
Блок: FEM → 3190
Параметр: Paddles_verbaut → aktiv

Блок: EGS → 3000
Параметры:
- Sportschalter → aktiv
- Sportschalter_alt → aktiv
```

> [!TIP] Эффект
> Лепестки за рулём позволяют вручную переключать передачи независимо от режима КПП.

---

## Поведение в ручном режиме

### Авто-возврат в автоматический режим

```
Блок: EGS
Параметр: MANUAL_MODE_TIMEOUT → настроить (секунды) || 0 = без возврата
```

### Блокировка понижения при высоких оборотах

```
Блок: EGS
Параметр: DOWNSHIFT_PROTECTION → aktiv
```

---

## Индикация режима на приборной панели

```
Блок: KOMBI
Параметры:
- MANUAL_MODE_DISPLAY → aktiv
- GEAR_INDICATOR_STYLE → M_Sport || Classic
```

---

## Интеграция с режимами вождения

```
Блок: [соответствующий]
Параметры:
- PADDLES_IN_ECO_PRO → aktiv/nicht_aktiv
- PADDLES_IN_COMFORT → aktiv
- PADDLES_IN_SPORT → aktiv (по умолчанию)
```

> [!TIP] Рекомендации
>
> - Включите лепестки в Comfort для большего контроля
> - Отключите в Eco Pro для экономии топлива

---

## Настройка отклика

```
Блок: EGS
Параметры:
- PADDLE_SHIFT_SPEED → fast || normal || smooth
- REV_MATCH_ON_DOWNSHIFT → aktiv (автоматическая перегазовка)
```

---

## Troubleshooting

| Проблема                  | Решение                                                 |
| ------------------------- | ------------------------------------------------------- |
| Лепестки не реагируют     | Проверить Paddles_verbaut, наличие физических лепестков |
| Переключения игнорируются | Проверить режим КПП, параметры EGS                      |
| Ошибка в блоке            | Выполнить адаптацию КПП, проверить совместимость версий |

---

> [!NOTE] Физическая установка
> Если лепестков нет на руле — кодирование не добавит их. Требуется установка комплекта лепестков и, возможно, замена руля/подрулевого переключателя.
