# Paddle Shifters (Лепестки КПП)

> [!IMPORTANT]
> **FEM_BODY, EGS** — F-series → FEM_BODY + EGS.
> Требуется наличие физических лепестков на руле.

---

## Активация переключения лепестками

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3190
Параметры:
- Paddles_verbaut → aktiv // Активация лепестков (default: nicht_aktiv)

Блок: EGS → 3000
Параметры:
- Sportschalter → aktiv     // Спортивная логика переключений
- Sportschalter_alt → aktiv // Спортивная логика (альтернативный)
- Applikation_LC → aktiv    // Launch Control (требует 2TB в FA)
```

> [!NOTE]
> Лепестки за рулём позволяют вручную переключать передачи независимо
> от режима КПП. Для полноценной работы рекомендуется активировать
> Sport Auto Transmission (2TB в FA).

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка         | Как проверить настройку / Решение                       |
| :------------------------ | :------------------------------------------------------ |
| Лепестки не реагируют     | Проверить Paddles_verbaut, наличие физических лепестков |
| Переключения игнорируются | Проверить режим КПП, Sportschalter в EGS                |
| Ошибка в блоке            | Выполнить адаптацию КПП, проверить совместимость версий |

---

> [!WARNING]
> Если лепестков нет на руле — кодирование не добавит их. Требуется
> установка комплекта лепестков и, возможно, замена рулевого
> переключателя (SZL).
