# Sport Mode & Driving Modes

> [!INFO] Блоки управления
> **ICM**, **EGS**, **DDE/DME**, **HU_NBT** — в зависимости от функции

---

## Активация режимов Sport+ и Comfort+

```
Блок: [соответствующий]
Параметры:
- DRIVING_EXPERIENCE_SWITCH → aktiv
- SPORT_PLUS_MODE → aktiv
- COMFORT_PLUS_MODE → aktiv
```

> [!TIP] Управление
> Режимы переключаются кнопкой рядом с селектором КПП:
>
> - Нажатие: Sport / Comfort / Eco Pro
> - Удержание: активация + (Sport+ / Comfort+)

---

## Спортивная логика АКПП

```
Блок: ICM
Параметр: IcmKod_B_S2TBA → verbaut
```

> [!TIP] Эффект
>
> - Более поздние переключения на повышенную
> - Более ранние сбросы на пониженную
> - Агрессивная реакция на педаль газа

---

## Поведение в режиме Eco Pro

### Отключение Start-Stop в Eco Pro

```
Блок: [соответствующий]
Параметр: ECO_CONF_MSA → nicht_aktiv
```

### Настройка рекуперации

```
Блок: DME → 3000
Параметр: IGR → Werte 00 (recuperation off = always charge)
```

> [!NOTE] Рекуперация
> По умолчанию АКБ заряжается до ~80%, оставляя 20% для рекуперации. Отключение = заряд до 100%, но +~3% к расходу топлива.

---

## Настройка отклика педали газа

```
Блок: [соответствующий]
Параметры:
- THROTTLE_RESPONSE_SPORT → настроить кривую
- THROTTLE_RESPONSE_COMFORT → настроить кривую
```

> [!WARNING] Осторожно
> Слишком агрессивная настройка может сделать управление нервозным.

---

## Дополнительные настройки режимов

### Сохранение последнего режима при запуске

```
Блок: [соответствующий]
Параметр: LAST_DRIVING_MODE_MEMORY → aktiv
```

### Отключение напоминаний о режиме

```
Блок: HU_NBT / KOMBI
Параметр: DRIVING_MODE_HINTS → nicht_aktiv
```

---

## Troubleshooting

| Проблема                | Решение                                                 |
| ----------------------- | ------------------------------------------------------- |
| Режимы не переключаются | Проверить кнопку, параметры активации, версию прошивки  |
| АКПП не меняет логику   | Убедиться, что закодирован ICM, выполнить адаптацию КПП |
| Ошибка в блоке          | Сбросить адаптации, проверить совместимость версий      |

---

> [!NOTE] Адаптация АКПП
> После изменений в настройках трансмиссии рекомендуется выполнить адаптацию через сервисные функции для применения новых параметров.
