# Adaptive Lighting

> [!IMPORTANT]
> **FEM**, **FRM**, **KAFAS** — в зависимости от комплектации и серии

---

## Адаптивное освещение поворотов (через ПТФ)

> [!NOTE]
>
> - Режим фар: **AUTO**
> - Время: **тёмное время суток**
> - Не на всех автомобилях (зависит от наличия ПТФ и проводки)

**Модели:** F20, F30, F34...

```
Блок: FEM → 3062
Параметры:
- MAPPING_abbiegel_L_output → nsw_l
- MAPPING_abbiegel_R_output → nsw_r

Блок: FEM → 3066
Параметры:
- KL_ENABLE_LI → KL_Ein
- KL_ENABLE_RE → KL_Ein

Блок: FEM → 3073
Параметры:
- C_BLC_ENA → F30enable
- C_CLC_ENA → F30enable
```

---

## Адаптивный свет через FRM (альтернатива)

```
Блок: FRM
Параметры:
- Lamp_map_para_satz_01 → BV_F025_WERT02_Corneringlight-UBER-NSW
- Lamp_map_para_satz_02 → BV_F025_WERT02_Corneringlight-UBER-NSW
- ALC_AFS_ENABLE → aktiv
- U_EFF_CL → FF (LED) или wert_07__13,0V = 82 (галоген)
```

---

## Настройка угла поворотного света

> [!NOTE]
> Требует наличия адаптивных фар или отдельного модуля

```
Блок: [зависит от комплектации]
Параметры:
- AFS_CORNERING_ANGLE → настроить значение
- AFS_SPEED_THRESHOLD → порог скорости активации
```

---

## Интеграция с противотуманными фарами

```
Блок: [соответствующий]
Параметр: CORNERING_LIGHT_VIA_FOG → aktiv
```

> [!NOTE]
> ПТФ работают как дополнительные поворотные огни при маневрировании на низкой скорости.

---

## Troubleshooting

| Проблема                      | Решение                                                     |
| ----------------------------- | ----------------------------------------------------------- |
| Адаптивный свет не включается | Проверить режим фар (AUTO), время суток, датчик дождя/света |
| Работает только одна сторона  | Проверить проводку, лампу, параметры MAPPING\_...           |
| Ошибка в блоке                | Выполнить калибровку фар через сервисные функции            |

---

> [!WARNING]
> После изменений в настройках освещения рекомендуется выполнить адаптацию фар через диагностический сканер или сервисное меню.
