# Fog Lights (ПТФ)

> [!IMPORTANT]
> **FEM_BODY, FRM, BDC_BODY** — F-series → FEM_BODY; G-series → BDC_BODY.
> Требуется наличие передних противотуманных фар.

---

## ПТФ остаются включёнными при дальнем свете

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3050
Параметры:
- NSW_AUS_BEI_FL → nicht_aktiv // ПТФ НЕ гаснут при включении дальнего (default: aktiv)
```

### Настройка параметров для G-серии

```text
Блок: BDC_BODY → 7083
Параметры:
- NSW_AUS_BEI_FL → nicht_aktiv // ПТФ НЕ гаснут при дальнем
```

### Таблица значений

| Поведение                        | Значение    |
| :------------------------------- | :---------- |
| ПТФ гаснут при дальнем (default) | aktiv       |
| ПТФ остаются при дальнем         | nicht_aktiv |

> [!NOTE]
> По умолчанию (aktiv) ПТФ гаснут при включении дальнего света.
> Значение `nicht_aktiv` позволяет ПТФ оставаться включёнными,
> создавая эффект стробоскопа при переключении.

---

## ПТФ при габаритных огнях

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3060
Параметры:
- NSW_EIN_AUF_LDS_STL → aktiv // ПТФ включаются при положении «габариты» (default: nicht_aktiv)
```

---

## ПТФ в Welcome Light

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3063
Параметры:
- MAPPING_NEBELSCHW_L_PART_OF_WL → Soft_On // Левая ПТФ в Welcome Light
- MAPPING_NEBELSCHW_R_PART_OF_WL → Soft_On // Правая ПТФ в Welcome Light
```

> [!NOTE]
> При разблокировке автомобиля ПТФ плавно включаются вместе с
> остальными элементами Welcome Light.

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка                  | Как проверить настройку / Решение                      |
| :--------------------------------- | :----------------------------------------------------- |
| ПТФ не гаснут / гаснут при дальнем | Проверить NSW_AUS_BEI_FL, статус датчика света         |
| ПТФ не включаются при габаритах    | Проверить NSW_EIN_AUF_LDS_STL, положение переключателя |
| Ошибка в блоке                     | Выполнить сброс адаптаций освещения                    |

---

> [!WARNING]
> В некоторых регионах эксплуатация ПТФ совместно с дальним светом
> запрещена ПДД. Проверьте местное законодательство.
