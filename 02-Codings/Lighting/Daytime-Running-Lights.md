# Daytime Running Lights (ДХО)

> [!IMPORTANT]
> **FEM_BODY, REM, HU_NBT, BDC_BODY** — F-series → FEM_BODY + REM;
> G-series → BDC_BODY.

---

## Пункт ДХО в меню iDrive

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3000
Параметры:
- DAYDRIVING_LIGHT → standart // Пункт «ДХО» в настройках освещения iDrive (werte=02)
```

### Настройка параметров для G-серии

```text
Блок: HU_NBT_EVO → 3000
Параметры:
- DAYDRIVING_LIGHT → standart // Пункт «ДХО» в настройках освещения iDrive
```

> [!NOTE]
> После кодирования: заглушить автомобиль → закрыть и открыть двери →
> завести. Пункт появится в: Настройки → Освещение → ДХО.

---

## Включение ДХО (режим работы)

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3060
Параметры:
- TFL_MODUS → Tfl_s // Включение ДХО (варианты: 0=Off, A=Auto, P=Parking, Tfl_s, Drl_s)
```

### Таблица значений TFL_MODUS

| Режим          | Значение      | Описание          |
| :------------- | :------------ | :---------------- |
| Выключено      | 0             | ДХО не горят      |
| Авто           | A             | ДХО в режиме AUTO |
| Парковка       | P             | ДХО при парковке  |
| ДХО (стандарт) | Tfl_s / Drl_s | Постоянные ДХО    |

## Яркость ДХО и Angel Eyes

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3062
Параметры:
- MAPPING_TAGFAHRL_V_L_PWM_LEVEL_1 → 64 // Яркость ДХО левая (HEX, 64 = 100%)
- MAPPING_TAGFAHRL_V_R_PWM_LEVEL_1 → 64 // Яркость ДХО правая (HEX, 64 = 100%)
- MAPPING_STANDL_V_L_PWM_LEVEL_1 → 32   // Яркость Angel Eyes левая (HEX, 32 = 50%)
- MAPPING_STANDL_V_R_PWM_LEVEL_1 → 32   // Яркость Angel Eyes правая (HEX, 32 = 50%)
- MAPPING_PARKL_V_L_PWM_LEVEL_1 → 32    // Яркость парковочных огней левая
- MAPPING_PARKL_V_R_PWM_LEVEL_1 → 32    // Яркость парковочных огней правая
```

### Таблица значений яркости

| Яркость | HEX |
| :------ | :-- |
| 0%      | 00  |
| 25%     | 19  |
| 50%     | 32  |
| 100%    | 64  |

> [!NOTE]
> Значения в HEX. По умолчанию для ДХО = 64 (100%), для Angel Eyes = 08.
> На F32 регулировка Angel Eyes может не работать.

## Задние габариты при работе ДХО

### Настройка параметров для F-серии

```text
Блок: REM → 3062
Параметры:
- MAPPING_TAGFAHRL_H_L_OUTPUT → sl_l    // Задний левый (внешний) с ДХО
- MAPPING_TAGFAHRL_H_R_OUTPUT → sl_r    // Задний правый (внешний) с ДХО
- MAPPING_TAGFAHRL_H2_L_OUTPUT → sl_2_l // Задний левый (внутренний) с ДХО
- MAPPING_TAGFAHRL_H2_R_OUTPUT → sl_2_r // Задний правый (внутренний) с ДХО
```

### Настройка параметров для G-серии

```text
Блок: BDC_BODY → 3702
Параметры:
- LIC_FEATURE_4 → aktiv // Задние габариты с ДХО
```

> [!NOTE]
> При включённых ДХО загораются задние габаритные огни для лучшей
> заметности автомобиля сзади.

### Яркость задних фонарей в режиме ДХО

```text
Блок: REM → 3062
Параметры:
- MAPPING_TAGFAHRL_H_L_PWM_LEVEL_1 → 64 // Яркость заднего левого с ДХО (HEX, 64 = 100%)
- MAPPING_TAGFAHRL_H_R_PWM_LEVEL_1 → 64 // Яркость заднего правого с ДХО (HEX, 64 = 100%)
```

## ДХО в Welcome Light

### Настройка параметров для F-серии

```text
Блок: FEM_BODY
Параметры:
- MAPPING_TAGFAHRL_V_L_PART_OF_WL → active // Передний левый ДХО в Welcome Light
- MAPPING_TAGFAHRL_V_R_PART_OF_WL → active // Передний правый ДХО в Welcome Light

Блок: REM
Параметры:
- MAPPING_TAGFAHRL_H_L_PART_OF_WL → active // Задний левый в Welcome Light
- MAPPING_TAGFAHRL_H_R_PART_OF_WL → active // Задний правый в Welcome Light
```

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка            | Как проверить настройку / Решение                      |
| :--------------------------- | :----------------------------------------------------- |
| Пункт в iDrive не появляется | Выполнить цикл зажигания, проверить версию HU_NBT      |
| ДХО не меняют яркость        | Проверить тип фар (LED/Xenon), наличие поддержки PWM   |
| Задние габариты не горят     | Проверить REM → 3062, все 4 параметра MAPPING_TAGFAHRL |

---

> [!WARNING]
> Отключение ДХО может снизить заметность автомобиля днём и нарушить
> ПДД в ряде стран. Проверьте законодательство перед изменением.
