# Daytime Running Lights (ДХО)

> [!IMPORTANT]
> **FEM**, **BDC**, **HU_NBT** — в зависимости от серии и комплектации

---

## Максимальная яркость ДХО во всех режимах

```
Блок: [соответствующий]
Параметр: DRL_BRIGHTNESS_MODE → maximum
```

> [!NOTE]
> ДХО работают на 100% яркости независимо от режима освещения (AUTO, габариты, ближний).

---

## Возможность выключения ДХО в настройках

```
Блок: HU_NBT → 3000 HMI
Параметр: DAYDRIVING_LIGHT → standart (werte = 02)
```

> [!NOTE]
> В меню iDrive появляется пункт "Постоянный ближний" / "ДХО" для ручного управления.

### Активация задних ДХО (если предусмотрено)

```
Блок: BDC_BODY
Параметр: Feature_4 → aktiv
```

### Порядок активации

1. Установить параметр в HU_NBT
2. Заглушить автомобиль
3. Закрыть и открыть двери
4. Завести — пункт появится в настройках освещения

---

## ДХО + габариты одновременно

```
Блок: [соответствующий]
Параметр: DRL_WITH_PARKING_LIGHTS → aktiv
```

> [!NOTE]
> Зависит от типа фар и проводки.

---

## Задние габариты при работе ДХО

```
Блок: [соответствующий]
Параметр: REAR_LIGHTS_WITH_DRL → aktiv
```

> [!TIP]
> При включённых ДХО загораются задние габариты для лучшей заметности автомобиля сзади.

---

## Отключение ДХО (не рекомендуется)

```
Блок: [соответствующий]
Параметр: DAYDRIVING_LIGHT → nicht_aktiv
```

> [!WARNING]
> Отключение ДХО может снизить заметность автомобиля днём.

---

## Troubleshooting

| Проблема                     | Решение                                           |
| ---------------------------- | ------------------------------------------------- |
| ДХО не меняют яркость        | Проверить тип фар, наличие поддержки регулировки  |
| Пункт в iDrive не появляется | Выполнить цикл зажигания, проверить HU_NBT версию |
| Ошибка в блоке               | Сбросить адаптации освещения                      |

---

> [!TIP]
> После кодирования:
>
> 1. Проверить работу ДХО при разных положениях переключателя света
> 2. Убедиться, что настройки в iDrive сохраняются
> 3. Протестировать яркость в дневное и ночное время
