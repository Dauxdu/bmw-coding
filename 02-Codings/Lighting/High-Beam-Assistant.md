# High Beam Assistant (5AC)

> [!IMPORTANT]
> **KAFAS(2)** — камера, **FEM** — электроника, **HU_NBT** — интерфейс

> [!WARNING]
> Требует после изменения FA обязательно пересчитать кодировку (FP) и закодировать все связанные блоки, ранние изменения будут сброшены до заводского состояния блока.

---

## Добавление опции 5AC в FA

```
1. Открыть FA автомобиля в E-Sys
2. Добавить опцию: 5AC
3. Нажать "Calculate FP"
4. Закодировать блоки: FEM, KOMBI, KAFAS(2)
```

---

## Изменение скорости срабатывания 5AC

**Модели:** F20, F30, F34...

```
Блок: KAFAS2 → 3050
Параметры:
- SPEED_SWITCHING_HIGH_BEAMS_ON → default 0x28 (40 км/ч)
- SPEED_SWITCHING_HIGH_BEAMS_OFF → default 0x1E (30 км/ч)
```

> [!NOTE]
>
> - Увеличьте значения для активации на более высокой скорости
> - Уменьшите для более раннего включения дальнего

| Значение (hex) | Скорость (км/ч) |
| -------------- | --------------- |
| 14             | 20              |
| 1E             | 30              |
| 28             | 40              |
| 32             | 50              |
| 3C             | 60              |

## Включение & отключение через интерфейс

```
Блок: KAFAS(2) → 3015
Параметр: FLA_ON_OFF → aktiv || on

Блок: HU_NBT2 → 3000
Параметр: HIGH_BEAM_ASSISTANT → aktiv

Блок: FEM → 3050
Параметр: FLA_AUTO_AKTIV → aktiv || automatisch

Блок: FEM_BODY
Параметр: FLA_VERBAUT → aktiv

Дополнительные параметры:
- FL_ASSIST_ENABLE → aktiv
- FL_ASSIST_FUNKTIONS_ANZ → aktiv
- FL_ASSIST_ZUST_22_32 → aktiv
```

## Настройка чувствительности камеры

```
Блок: KAFAS(2)
Параметры:
- SENSITIVITY_ONCOMING_TRAFFIC → настроить
- SENSITIVITY_PRECEDING_VEHICLE → настроить
- LIGHT_THRESHOLD_DARKNESS → настроить
```

## Troubleshooting

| Проблема                 | Решение                                                 |
| ------------------------ | ------------------------------------------------------- |
| 5AC не активируется      | Проверить наличие камеры, кодировку, опцию в FA         |
| Дальний не переключается | Проверить скорость, встречный транспорт, чистоту камеры |
| Ошибка в KAFAS           | Выполнить калибровку камеры через сервисные функции     |
