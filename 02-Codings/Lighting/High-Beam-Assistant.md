# High Beam Assistant (5AC)

> [!IMPORTANT]
> **KAFAS2, FEM_BODY, HU_NBT** — требуется камера KAFAS2 и опция 5AC.
> После изменения FA обязательно пересчитать FP и закодировать все
> связанные блоки.

---

## Добавление опции 5AC в FA (VO Coding)

### Процедура для F-серии

```text
1. Открыть FA автомобиля в E-Sys
2. Удалить опцию 5AP (если присутствует)
3. Нажать «Calculate FP»
4. Закодировать блоки: FEM_BODY, FLA/KAFAS2
```

> [!NOTE]
> Рекомендуется также активировать Variable Light Distribution
> (удалить 8S4 из FA → VO Code FEM_BODY) для полноценной работы
> Active High Beam Assistant.

---

## Скорость срабатывания дальнего света

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3050
Параметры:
- SPEED_SWITCHING_HIGH_BEAMS_ON → 28  // Включение дальнего при 40 км/ч (HEX, default: 28)
- SPEED_SWITCHING_HIGH_BEAMS_OFF → 1E // Выключение дальнего при 30 км/ч (HEX, default: 1E)
```

### Таблица значений скорости

| HEX | км/ч |
| :-- | :--- |
| 14  | 20   |
| 1E  | 30   |
| 28  | 40   |
| 32  | 50   |
| 3C  | 60   |

## Параметры HBA в FEM_BODY

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3050
Параметры:
- C_HBA_ENA_V_HI → user   // Скорость активации HBA (HEX, км/ч)
- C_HBA_ENA_V_LO → user   // Скорость деактивации HBA (HEX, км/ч)
- C_HBA_HGWY_V_HI → 8C    // Вход в Highway Mode при 140 км/ч (default: 8C)
- C_HBA_HGWY_V_LO → 5A    // Выход из Highway Mode при 90 км/ч (default: 5A)
```

## Включение FLA через интерфейс

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3015
Параметры:
- FLA_ON_OFF → aktiv // Включение функции FLA

Блок: FEM_BODY → 3050
Параметры:
- FLA_AUTO_AKTIV → aktiv // Авто-режим дальнего по умолчанию (default: nicht_aktiv)
```

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка        | Как проверить настройку / Решение                          |
| :----------------------- | :--------------------------------------------------------- |
| 5AC не активируется      | Проверить наличие камеры KAFAS2, опцию 5AC в FA, кодировку |
| Дальний не переключается | Проверить скорость, встречный транспорт, чистоту камеры    |
| Ошибка в KAFAS           | Выполнить калибровку камеры через сервисные функции        |
