# Turn Signals (Поворотники)

> [!IMPORTANT]
> **FEM_BODY, KOMBI, HU_NBT** — F-series → FEM_BODY.
> HUD-индикация требует дисплей 6WA (Extended).

---

## Нефиксируемые (мягкие) поворотники

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3075
Параметры:
- FS_TYP_SZL → nicht_rastend // Нефиксируемый рычаг поворотника (default: rastend)

Блок: FEM_BODY → 3140
Параметры:
- LIN_VARIANTE_SZL → szl_aic_4Band_fla // Вариант SZL для мягких поворотников
```

### Расшифровка LIN_VARIANTE_SZL

| Аббревиатура | Значение                        |
| :----------- | :------------------------------ |
| szl          | Steering column formwork center |
| aic          | Automatic interval control      |
| 4Band        | 4-позиционный переключатель     |
| fla          | Front light assist              |

> [!NOTE]
> Лёгкое нажатие на рычаг включает поворотник на 3–5 миганий без
> фиксации. Удобно для перестроений.

---

## Количество миганий поворотника

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3060
Параметры:
- BLINKZYKLEN_ANZAHL_TIPP → werte=X-1 // Количество миганий (default: 02 = 3 мигания)
```

### Таблица значений

| Миганий     | HEX (werte) |
| :---------- | :---------- |
| 3 (default) | 02          |
| 4           | 03          |
| 5           | 04          |

## LED-поворотники (замена ламп на LED)

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3061
Параметры:
- FRA_V_L_KALTUEBERWACHUNG → nicht_aktiv  // Отключить холодный мониторинг передний левый
- FRA_V_L_WARMUEBERWACHUNG → nicht_aktiv  // Отключить тёплый мониторинг передний левый
- FRA_V_L_IS_LED → aktiv                  // Включить распознавание LED передний левый
- FRA_V_R_KALTUEBERWACHUNG → nicht_aktiv  // Отключить холодный мониторинг передний правый
- FRA_V_R_WARMUEBERWACHUNG → nicht_aktiv  // Отключить тёплый мониторинг передний правый
- FRA_V_R_IS_LED → aktiv                  // Включить распознавание LED передний правый

Блок: FEM_BODY/REM → 3061
Параметры:
- FRA_H_L_KALTUEBERWACHUNG → nicht_aktiv  // Отключить холодный мониторинг задний левый
- FRA_H_L_WARMUEBERWACHUNG → nicht_aktiv  // Отключить тёплый мониторинг задний левый
- FRA_H_L_IS_LED → aktiv                  // Включить распознавание LED задний левый
- FRA_H_R_KALTUEBERWACHUNG → nicht_aktiv  // Отключить холодный мониторинг задний правый
- FRA_H_R_WARMUEBERWACHUNG → nicht_aktiv  // Отключить тёплый мониторинг задний правый
- FRA_H_R_IS_LED → aktiv                  // Включить распознавание LED задний правый
```

> [!NOTE]
> Без этих параметров LED-лампы вызывают мерцание из-за импульсной
> проверки целостности нити накала каждые 4 минуты. Рекомендуемые
> лампы: CREE 30W XB-D5 LED.

---

## Индикация поворотников в HUD

### Настройка параметров для F-серии

```text
Блок: HU_NBT → 3001
Параметры:
- HUD_TURNSIGNAL → aktiv // Поворотники в HUD (Part 1)

Блок: KOMBI → 3008
Параметры:
- HUD_PIA_BLINKER → aktiv // Поворотники в HUD (Part 2)

Блок: KOMBI → 3000
Параметры:
- BLINKER_HUD_ENABLE → aktiv // Поворотники в HUD (Part 3)
```

> [!NOTE]
> Работает только на дисплеях 6WA (Extended). На F30 подтверждена
> неработоспособность (PDF v1.7: «Not working on F30»). На 6WB
> (Basic) не работает.

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка              | Как проверить настройку / Решение                                      |
| :----------------------------- | :--------------------------------------------------------------------- |
| Мягкие поворотники не работают | Проверить FS_TYP_SZL + LIN_VARIANTE_SZL, совместимость рулевой колонки |
| LED мерцают                    | Проверить все 6 параметров FRA\__\_IS_LED и _\_UEBERWACHUNG            |
| Поворотники не в HUD           | Убедиться в наличии 6WA; на F30 функция не работает                    |

---

> [!WARNING]
> При установке LED-ламп в задние поворотники параметр `FRA_H_*_IS_LED`
> может вызвать Check Engine Light. Проверьте совместимость с вашей
> версией прошивки REM.
