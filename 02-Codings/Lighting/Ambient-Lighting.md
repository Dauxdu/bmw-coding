# Ambient Lighting

> [!IMPORTANT]
> **FEM_BODY, BDC_BODY** — F-series → FEM_BODY; G-series → BDC_BODY.

---

## Яркость амбиентной подсветки

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3070
Параметры:
- Ambiente_Helligkeit → user          // Яркость подсветки (HEX, default: 64 = 100%)
- Ambiente_Nachfuehrung → nicht_aktiv // Отвязка от яркости KOMBI (default: aktiv)
```

---

## Яркость Welcome Light

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3070
Параметры:
- WL_HELLIGKEIT → user // Яркость Welcome Light (HEX, default: 64)
```

---

## Время подсветки при блокировке/разблокировке

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3070
Параметры:
- IB_Einschalt_begr_lok → user   // Время подсветки при блокировке (HEX сек, default: 8)
- IB_Einschalt_begr_ulok → user  // Время подсветки при разблокировке (HEX сек, default: 8)
```

---

## Подсветка ручек при задней передаче

### Настройка параметров для F-серии

```text
Блок: FEM_BODY → 3070
Параметры:
- OVT_BEI_RUECKFAHRLICHT → aktiv // LED ручек дверей при задней передаче (default: nicht_aktiv)
```

> [!NOTE]
> На автомобилях с Top-View Camera эта функция уже активна по умолчанию.

---

## Цвета амбиентной подсветки (G-series)

### Настройка параметров для G-серии

```text
Блок: BDC_BODY → 360A
Параметры:
- LIC_LCI_COLOR_LIBRARY_DATA → custom RGB // Пользовательские цвета подсветки салона
```

### Таблица значений RGB

| Цвет       | RGB (HEX)  |
| :--------- | :--------- |
| Белый      | 90, E0, 90 |
| Бронза     | D7, 6E, 14 |
| Оранжевый  | 93, 1A, 01 |
| Синий      | 00, 20, FE |
| Зелёный    | 10, FE, 32 |
| Фиолетовый | 78, 3C, FE |

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка           | Как проверить настройку / Решение                     |
| :-------------------------- | :---------------------------------------------------- |
| Подсветка не меняет яркость | Проверить Ambiente_Helligkeit, наличие опции амбиента |
| Подсветка привязана к KOMBI | Установить Ambiente_Nachfuehrung → nicht_aktiv        |
| Цвета не применяются (G)    | Проверить LIC_LCI_COLOR_LIBRARY_DATA, версию BDC_BODY |

---

> [!WARNING]
> Изменение цветов подсветки в G-series требует совместимой версии
> прошивки BDC_BODY. Сохраните резервную копию перед изменением.
