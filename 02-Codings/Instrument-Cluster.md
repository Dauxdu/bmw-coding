# Instrument Cluster (KOMBI)

> [!INFO] Блок управления
> **KOMBI** — приборная панель (6WA, 6WB, ID6, ID7)

---

## Цифровой спидометр

```
Блок: KOMBI
Параметр: DIGITAL_SPEEDOMETER → aktiv
```

> [!TIP] Эффект
> Текущая скорость отображается цифрами в центре тахометра или на дисплее.

---

## Дублирование поворотников на дисплее

```
Блок: KOMBI → 3008
Параметр: HUD_PIA_BLINKER → aktiv

Блок: KOMBI → 3000
Параметр: BLINKER_HUD_ENABLE → aktiv
```

> [!NOTE] Также требует
> Настройки в [[HUD]] для полного функционала.

---

## Логотип M Performance при запуске

```
Блок: KOMBI
Параметр: WELCOME_LOGO → M_Performance || BMW_M || Custom
```

> [!TIP] Варианты
>
> - `BMW_Standard` — обычный логотип
> - `BMW_M` — логотип M
> - `M_Performance` — логотип M Performance
> - `Custom` — пользовательский (требует модификации)

---

## Индикация температуры шин

```
Блок: HU_NBT → 3001
Параметр: RDC_DRUCK_TEMP → druck_und_temperatur
```

> [!NOTE] Требует
> Датчиков давления с поддержкой температуры (входят в опцию 2VB).

---

## Стиль приборной панели

```
Блок: KOMBI
Параметр: DISPLAY_STYLE → M_Sport || Classic || Eco_Pro
```

> [!TIP] Зависит от
> Комплектации и версии прошивки. Не все стили доступны на всех авто.

---

## Настройка предупреждений

```
Блок: KOMBI
Параметры:
- SEATBELT_WARNING → aktiv/nicht_aktiv
- DOOR_OPEN_WARNING → aktiv
- LOW_FUEL_WARNING_THRESHOLD → настроить уровень
```

---

## Сброс сервисных интервалов через кодировку

> [!WARNING] Не рекомендуется
> Лучше использовать сервисные функции. Кодировка может вызвать ошибки.

```
Блок: KOMBI
Параметры:
- SERVICE_RESET_ENABLE → aktiv (только для отладки!)
```

---

## Troubleshooting

| Проблема                           | Решение                                                            |
| ---------------------------------- | ------------------------------------------------------------------ |
| Цифровой спидометр не отображается | Проверить параметр, версию прошивки KOMBI                          |
| Логотип не меняется                | Убедиться, что файл логотипа совместим                             |
| Ошибка в блоке                     | Не отключать питание во время кодирования, проверить совместимость |

---

> [!WARNING] Важно
> При кодировании KOMBI:
>
> - Не отключайте питание
> - Используйте стабильное напряжение (подключите ЗУ)
> - Сохраните резервную копию оригинальной кодировки
