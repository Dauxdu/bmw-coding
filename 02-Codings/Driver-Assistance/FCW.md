# FCW (Forward Collision Warning)

> [!IMPORTANT]
> **KAFAS2, ICM, KOMBI** — KAFAS2 = камера; ICM = шасси; KOMBI = отображение.

---

## Настройка параметров предупреждения

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3060
Параметры:
- driver_warning → FF                  // Тип предупреждения: визуал+звук+вибрация (default: AB)
- speed_thrv_fcw_acute_dynamic → 0A    // Порог скорости «острого» предупреждения (default: 0F)
- speed_thrv_fcw_advance_dynamic → 0A  // Порог «предварительного» предупреждения (default: 0F)
- min_time_advance_warn → 0A           // Мин. время до раннего предупреждения (default: 0F)
- min_time_acute_warn → 0F             // Мин. время для острого предупреждения (default: 14)
- max_dist_acute → 55                  // Макс. дистанция острого предупреждения, м (default: 46)
- fix_warn_flav → 01                   // Тип фиксированного предупреждения (default: 02)
```

### Таблица значений driver_warning

| HEX          | Тип предупреждения                      |
| :----------- | :-------------------------------------- |
| AB (default) | Стандартный набор                       |
| FF           | Визуал + звук + вибрация (максимальный) |

---

## Параметры TTC (Time-To-Collision)

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3070
Параметры:
- TTC_THRV_ADV_EARLY → 3C               // TTC раннего предупреждения (default: 30)
- TTC_THRV_ACUTE_EARLY → 30             // TTC острого предупреждения (default: 20)
- TTC_THRV_SHIFT_BRAKE_ACUTE_EARLY → 28 // TTC при торможении, раннее (default: 1E)
- TTC_THRV_SHIFT_BRAKE_ACUTE_LATE → 28  // TTC при торможении, позднее (default: 1E)
```

> [!NOTE]
> **Time-To-Collision** — расчётное время до столкновения. Меньшее
> значение = более раннее предупреждение. HEX-значения.

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка                  | Как проверить настройку / Решение                     |
| :--------------------------------- | :---------------------------------------------------- |
| Предупреждения не срабатывают      | Проверить скорость, дистанцию, параметры FCW_CODING   |
| Слишком частые ложные срабатывания | Увеличить пороги времени/дистанции                    |
| Ошибка в KAFAS                     | Выполнить калибровку камеры, проверить чистоту стекла |

---

> [!WARNING]
> Не устанавливайте слишком «ранние» параметры — это приведёт к
> постоянным ложным срабатываниям. Изменяйте значения постепенно.
