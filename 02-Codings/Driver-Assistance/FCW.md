# FCW (Forward Collision Warning)

> [!IMPORTANT]
> **KAFAS(2)** — камера, **ICM** — шасси, **KOMBI** — отображение

---

## Настройка параметров предупреждения

### Блок: KAFAS2 → 3060 FCW_CODING

| Параметр                       | Значение по умолчанию | Рекомендуемое | Описание                                              |
| ------------------------------ | --------------------- | ------------- | ----------------------------------------------------- |
| driver_warning                 | AB (171)              | **FF (255)**  | Тип предупреждения (визуал+звук+вибрация)             |
| speed_thrv_fcw_acute_dynamic   | 0F (15)               | **0A (10)**   | Порог скорости для "острого" предупреждения           |
| speed_thrv_fcw_advance_dynamic | 0F (15)               | **0A (10)**   | Порог для "предварительного" предупреждения           |
| min_time_advance_warn          | 0F (15)               | **0A (10)**   | Мин. время до столкновения для раннего предупреждения |
| min_time_acute_warn            | 14 (20)               | **0F (15)**   | Мин. время для острого предупреждения                 |
| max_dist_acute                 | 46                    | **55**        | Макс. расстояние для острого предупреждения (м)       |
| fix_warn_flav                  | 02                    | **01**        | Тип фиксированного предупреждения (менее навязчивый)  |

### Блок: KAFAS2 → 3070 FCW_WARNING_PARAMETERS

| Параметр                         | По умолчанию | Рекомендуемое | Описание                                         |
| -------------------------------- | ------------ | ------------- | ------------------------------------------------ |
| TTC_THRV_ADV_EARLY               | 30           | **3C**        | Время до столкновения для раннего предупреждения |
| TTC_THRV_ACUTE_EARLY             | 20           | **30**        | Время для острого предупреждения                 |
| TTC_THRV_SHIFT_BRAKE_ACUTE_EARLY | 1E           | **28**        | Предупреждение при торможении (раннее)           |
| TTC_THRV_SHIFT_BRAKE_ACUTE_LATE  | 1E           | **28**        | Предупреждение при торможении (позднее)          |

> [!NOTE]
> **Time-To-Collision** — расчётное время до столкновения. Меньшее значение = более раннее предупреждение.

---

## Типы предупреждений

```
Блок: KAFAS2
Параметры:
- FCW_VISUAL_WARNING → aktiv
- FCW_ACOUSTIC_WARNING → aktiv
- FCW_HAPTIC_WARNING → aktiv (если поддерживается)
```

---

## Чувствительность системы

```
Блок: KAFAS2
Параметры:
- FCW_SENSITIVITY → early || normal || late
- OBJECT_DETECTION_RANGE → настроить дистанцию
```

---

## Включение & отключение системы

```
Блок: [соответствующий]
Параметр: FCW_SYSTEM_ACTIVE → aktiv
```

> [!NOTE]
> В большинстве моделей водитель может временно отключить FCW через меню iDrive.

---

## Troubleshooting

| Проблема                           | Решение                                                        |
| ---------------------------------- | -------------------------------------------------------------- |
| Предупреждения не срабатывают      | Проверить скорость, дистанцию, параметры FCW_CODING            |
| Слишком частые ложные срабатывания | Увеличить пороги времени/дистанции, настроить чувствительность |
| Ошибка в KAFAS                     | Выполнить калибровку камеры, проверить крепление и чистоту     |

---

> [!WARNING]
> Не устанавливайте слишком "ранние" параметры — это может привести к постоянным ложным срабатываниям.
