# Traffic Sign Recognition

> [!IMPORTANT]
> **KAFAS2, KOMBI, HUD** — KAFAS2 = камера распознавания;
> KOMBI/HUD = отображение знаков.

---

## Настройка региона распознавания

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3000
Параметры:
- COUNTRY_VARIATION → ECE                // Регион камеры (default: зависит от рынка, USA = 03)
- TSM_COUNTRY_VARIATION → ECE            // Регион распознавания знаков (default: зависит от рынка, USA = 02)
- COD_CAM_ONLY → fusion_mode             // Камера + данные навигации (default: fusion_mode = 01)
- COUNTRY_CODING_DISPLAY → country_specific // Отображение знаков по стране (default: country_specific = 02)
```

> [!NOTE]
> `ECE` — европейский стандарт дорожных знаков (применим для РФ/СНГ).

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка     | Как проверить настройку / Решение                                  |
| :-------------------- | :----------------------------------------------------------------- |
| Знаки не распознаются | Проверить COUNTRY_VARIATION, TSM_COUNTRY_VARIATION, чистоту камеры |
| Неправильные знаки    | Убедиться, что выбран ECE для РФ/СНГ в обоих параметрах            |
| Знаки не отображаются | Проверить параметры в KOMBI/HUD                                    |

---

> [!WARNING]
> Распознавание знаков работает только при хорошей видимости и чистом
> лобовом стекле в зоне камеры. Может не распознавать временные и
> нестандартные знаки.
