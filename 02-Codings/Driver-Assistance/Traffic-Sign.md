# Traffic Sign Recognition

> [!IMPORTANT]
> **KAFAS2, KOMBI, HUD** — KAFAS2 = камера распознавания;
> KOMBI/HUD = отображение знаков.

---

## Настройка региона распознавания

### Настройка параметров для F-серии

```text
Блок: KAFAS2 → 3000
Параметры:
- COUNTRY_VARIATION → ECE            // Регион: европейский стандарт (default: зависит от рынка)
- COD_CAM_ONLY → camera_only         // Только камера, без данных навигации
- COUNTRY_CODING_DISPLAY → ECE_white // Белый фон для отображения знаков
```

> [!NOTE]
> `ECE` — европейский стандарт дорожных знаков (применим для РФ/СНГ).
> `camera_only` — использование только данных камеры без привязки
> к навигационным картам.

---

## Вариант отображения линий LDW

### Настройка параметров для F-серии

```text
Блок: KAFAS → 3000
Параметры:
- ANZEIGEVARIANTE → anz_var_02 // Линии LDW только при обнаружении разметки (default: anz_var_04)
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка     | Как проверить настройку / Решение           |
| :-------------------- | :------------------------------------------ |
| Знаки не распознаются | Проверить COUNTRY_VARIATION, чистоту камеры |
| Неправильные знаки    | Убедиться, что выбран ECE для РФ/СНГ        |
| Знаки не отображаются | Проверить параметры в KOMBI/HUD             |

---

> [!WARNING]
> Распознавание знаков работает только при хорошей видимости и чистом
> лобовом стекле в зоне камеры. Может не распознавать временные и
> нестандартные знаки.
