# Руководство по внесению изменений

1. Тестируйте на своем автомобиле
2. Указывайте:
   - Модель (F30, G20, etc.)
   - Год выпуска
   - Версию прошивки
3. Добавляйте скриншоты
4. Описывайте возможные проблемы
5. Поддерживайте оба языка: у каждого `Name.md` (английский) рядом
   лежит `Name.ru.md` (русский). Если пишете только на одном языке —
   укажите это в PR, второй добавим позже.
