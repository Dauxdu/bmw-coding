# Contributing

1. Test on your own vehicle
2. Specify:
   - Model (F30, G20, etc.)
   - Model year
   - Firmware version
3. Add screenshots
4. Describe possible problems
5. Keep both languages in sync: every `Name.md` (English) has a
   `Name.ru.md` (Russian) next to it. If you can only write one language,
   say so in the PR and the other will be added later.
