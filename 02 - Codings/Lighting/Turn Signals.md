# Turn Signals (Поворотники)

> [!INFO] Блоки управления
> **FEM**, **SZL**, **KOMBI**, **HUD** — в зависимости от функции

---

## Нефиксируемые (мягкие) поворотники

**Модели:** F20, F30, F34...

```
Блок: FEM → 3075 LceFuSiConfiguration
Параметр: FS_TYP_SZL (02 UNBELEGT) → nicht_rastend (UNK_PARAM_0)

Блок: FEM → 3140 PFLinSteeringWheel
Параметр: LIN_VARIANTE_SZL → szl_aic_4Band_fla
```

### Расшифровка параметров

| Опция | Значение                                       |
| ----- | ---------------------------------------------- |
| szl   | steering column formwork center                |
| r     | latching (отсутствует в нефиксируемых версиях) |
| HW    | Rear Window Wiper                              |
| aic   | automatic interval control                     |
| fla   | front light assist                             |

> [!TIP] Эффект
> Лёгкое нажатие на рычаг включает поворотник на 3-5 миганий без фиксации. Удобно для перестроений.

---

## Дублирование поворотников в проекционном дисплее (HUD)

> [!NOTE] Работает только на дисплеях 6WA (на 6WB не работает)

```
Блок: HU_NBT → 3001
Параметр: HUD_TURNSIGNAL → aktiv

Блок: KOMBI → 3008
Параметр: HUD_PIA_BLINKER → aktiv

Блок: KOMBI → 3000
Параметр: BLINKER_HUD_ENABLE → aktiv
```

### Активация в меню

После кодирования в NBT появится пункт:

```
Настройки → Проекционный дисплей → Индикация поворотников
```

---

## Частота мигания поворотников

```
Блок: [соответствующий]
Параметр: BLINKER_FREQUENCY → настроить значение
```

> [!WARNING] Законность
> Изменение частоты может не соответствовать стандартам. Используйте осторожно.

---

## Подсветка поворотников в зеркалах

```
Блок: [соответствующий]
Параметр: MIRROR_TURN_SIGNAL_LIGHT → aktiv
```

---

## Troubleshooting

| Проблема                          | Решение                                                            |
| --------------------------------- | ------------------------------------------------------------------ |
| Мягкие поворотники не работают    | Проверить LIN_VARIANTE_SZL, совместимость рулевой колонки          |
| Поворотники не отображаются в HUD | Убедиться, что установлен дисплей 6WA, проверить все три параметра |
| Ошибка в блоке                    | Сбросить адаптации, проверить совместимость версий                 |

---

> [!NOTE] Проверка
> После кодирования:
>
> 1. Протестировать лёгкое и полное нажатие рычага поворотника
> 2. Проверить отображение в HUD (если активировано)
> 3. Убедиться, что настройки сохраняются после перезапуска
