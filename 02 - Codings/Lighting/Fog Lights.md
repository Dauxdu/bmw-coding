# Fog Lights (ПТФ)

> [!INFO] Блоки управления
> **FEM** — Front Electronics Module, **FRM** — Footwell Module (в зависимости от модели)

---

## ПТФ гаснут при включении дальнего (эффект стробоскопа)

**Модели:** F20, F30, F34...

```
Блок: FEM → 3060 LceMaster
Параметр: NSW_AUS_BEI_FL → aktiv
```

> [!TIP] Эффект
> При переключении на дальний свет противотуманные фары кратковременно гаснут, создавая эффект стробоскопа. Улучшает заметность автомобиля.

> [!WARNING] Законность
> В некоторых регионах такой режим может быть запрещён.

---

## Адаптивное освещение поворотов ПТФ

> [!NOTE] Условия работы
>
> - Только в режиме фар **AUTO**
> - Только в **тёмное время суток**
> - Работает не на всех автомобилях (зависит от комплектации)

**Модели:** F20, F30, F34...

```
Блок: FEM → 3062
Параметры:
- MAPPING_abbiegel_L_output → nsw_l
- MAPPING_abbiegel_R_output → nsw_r

Блок: FEM → 3066
Параметры:
- KL_ENABLE_LI → KL_Ein
- KL_ENABLE_RE → KL_Ein

Блок: FEM → 3073
Параметры:
- C_BLC_ENA → F30enable
- C_CLC_ENA → F30enable
```

> [!TIP] Эффект
> При повороте руля включается соответствующая противотуманная фара для подсветки зоны поворота.

---

## Альтернативная настройка через FRM (для некоторых моделей)

```
Блок: FRM
Параметры:
- Lamp_map_para_satz_01 → BV_F025_WERT02_Corneringlight-UBER-NSW
- Lamp_map_para_satz_02 → BV_F025_WERT02_Corneringlight-UBER-NSW
- ALC_AFS_ENABLE → aktiv
- U_EFF_CL → FF (для LED) или wert_07__13,0V = 82 (для галогена)
```

## Troubleshooting

| Проблема                    | Решение                                                  |
| --------------------------- | -------------------------------------------------------- |
| ПТФ не гаснут при дальнем   | Проверить NSW_AUS_BEI_FL, статус датчика света           |
| Адаптивный свет не работает | Убедиться, что фары в режиме AUTO, проверить время суток |
| Ошибка в блоке              | Выполнить сброс адаптаций освещения                      |

---

> [!NOTE] Проверка
> После кодирования протестируйте функции:
>
> 1. Включите фары в AUTO
> 2. Дождитесь темноты или закройте датчик света
> 3. Проверьте работу при повороте руля и переключении на дальний
