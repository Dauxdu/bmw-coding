# Start-Stop (MSA)

> [!INFO] Блоки управления
> **CAS**, **FEM**, **BDC**, **DDE/DME**, **IHKA** — в зависимости от серии и года выпуска

---

## Запоминание последней настройки Start-Stop

### Модели F01, F10, F25...

```
Блок: CAS → 3000
Параметр: TCM_MSA_MEMORY → aktiv
```

### Модели F20, F30, F34...

```
Блок: FEM → 3000
Параметр: TCM_MSA_MEMORY → aktiv
```

### Модели F15, F56...

```
Блок: BDC
[Параметры зависят от версии прошивки]
```

### E-Series

```
Блок: IHKA
[Настройки в климат-контроле]
```

### G-Series

```
Блок: DDE/DME
Параметр: TCM_MSA_MEMORY → aktiv
⚠️ Требуется прошивка блока при выключенном двигателе с включённым зажиганием
```

> [!TIP] Эффект
> Система запоминает последнее состояние кнопки Start-Stop и восстанавливает его при следующем запуске.

---

## Значение Start-Stop по умолчанию (выключено)

### Модели F01, F10, F25...

```
Блок: CAS → 3000
Параметр: TC_MSA_DEFAULT_OFF → aktiv
```

### Модели F20, F30, F34...

```
Блок: FEM → 3000
Параметр: TC_MSA_DEFAULT_OFF → aktiv
```

### Модели F15, F56...

```
Блок: BDC
[Параметры зависят от версии прошивки]
```

### E-Series

```
Блок: IHKA
```

### G-Series

```
Блок: DDE/DME
Параметр: TC_MSA_DEFAULT_OFF → aktiv
⚠️ Только с включённым зажиганием, требуется прошивка
```

> [!WARNING] Важно
> На некоторых моделях параметр сбрасывается после обновления прошивки.

---

## Eco Pro не включает Start-Stop

```
Блок: [соответствующий]
Параметр: ECO_CONF_MSA → nicht_aktiv
```

> [!TIP] Эффект
> При выборе режима Eco Pro система не активирует Start-Stop автоматически.

---

## Дополнительные параметры

### Отключение напоминания о Start-Stop

```
Блок: KOMBI / HU_NBT
Параметр: MSA_REMINDER → nicht_aktiv
```

### Изменение условий активации

```
Блок: DDE/DME
Параметры:
- Температура АКБ
- Уровень заряда
- Нагрузка на генератор
[Требует углублённой настройки]
```

## Troubleshooting

| Проблема                        | Решение                                                         |
| ------------------------------- | --------------------------------------------------------------- |
| Настройка не сохраняется        | Проверить TCM_MSA_MEMORY, обновить прошивку блока               |
| Start-Stop работает некорректно | Проверить состояние АКБ, датчиков, выполнить адаптацию          |
| Ошибка после кодирования        | Вернуть исходные значения, проверить совместимость версии E-Sys |
