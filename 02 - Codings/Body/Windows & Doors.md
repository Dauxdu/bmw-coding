# Windows & Doors

> [!INFO] Блоки управления
> **FEM/REM** — Front/Rear Electronics Module, **FRM** — Footwell Module, **BDC** — Body Domain Controller

---

## Отключение блокировки стёкол при открытии двери

### Модели F20, F30, F34...

```
Блоки: FEM, REM
Параметр: FH_TUERAUF_STOP_MAUT → nicht_aktiv
```

### Модели F01, F10, F25...

```
Блоки: FRM, JBBF
Параметр: FH_TUER_AUF_STOP_MAUT → nicht_aktiv
```

### Модели F15, F56...

```
Блок: BDC
Параметры:
- FH_TUER_AUF_STOP_MAUT → nicht_aktiv
- FH_TUER_AUF_STOP_MAUT_REAR → nicht_aktiv
```

> [!TIP] Эффект
> Стеклоподъёмники продолжают работать при открытой двери (удобно для проветривания).

---

## Автоматическое закрытие стёкол

> [!NOTE] Стандартная функция
> Активируется долгим нажатием кнопки закрытия на ключе. Не требует кодирования.

---

## Блокировка дверей при движении

```
Блок: FEM, REM
Параметр: AUTOMATIC_CENTRAL_LOCKING → aktiv
```

> [!WARNING] Безопасность
> Включайте только если уверены в необходимости. Может помешать экстренной эвакуации.

---

## Подсветка ручек при разблокировке

```
Блок: FEM, REM
Параметр: WELCOME_LIGHTS → aktiv
```

---

## Troubleshooting

| Проблема              | Решение                                                          |
| --------------------- | ---------------------------------------------------------------- |
| Стекло не поднимается | Проверить FH_TUERAUF_STOP_MAUT, инициализировать стеклоподъёмник |
| Двери не блокируются  | Проверить статус центрального замка, предохранители              |
| Ошибка в блоке        | Выполнить сброс адаптаций через сервисные функции                |

---

> [!NOTE] Инициализация стеклоподъёмников
> После отключения АКБ или замены блока:
>
> 1. Поднять стекло до конца и удержать кнопку 3 сек
> 2. Опустить стекло до конца и удержать кнопку 3 сек
