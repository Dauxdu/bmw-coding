# Mirrors

---

## Парковочный наклон правого зеркала

### Настройка угла наклона

```
Блок: BDC_BODY
Параметр: ASP_BORDSTEINAUTOMATIK_DELTA
```

| Угол наклона  | Значение (hex) |
| ------------- | -------------- |
| 90° (default) | 5A             |
| 80°           | 50             |
| 70°           | 46             |
| 59°           | 3B             |

> [!TIP] Как работает
> При включении задней передачи правое зеркало наклоняется вниз для лучшего обзора бордюра. Возвращается в исходное положение при скорости >15-20 км/ч.

### Активация функции

```
Блок: [соответствующий]
Параметр: ASP_Curb_monitoring → aktiv
```

---

## Складывание зеркал без задержки

```
Блок: [соответствующий]
Параметр: MIRROR_FOLDING_DELAY → 00
```

> [!NOTE] Стандартное поведение
> По умолчанию зеркала складываются с задержкой 1-2 секунды после закрытия авто.

## Troubleshooting

| Проблема                | Решение                                             |
| ----------------------- | --------------------------------------------------- |
| Зеркало не наклоняется  | Проверить ASP параметры, выполнить адаптацию зеркал |
| Зеркало не возвращается | Проверить скорость срабатывания, калибровку         |
| Ошибка в блоке          | Сбросить адаптации через сервисные функции          |

---

> [!WARNING] Важно
> После изменений в параметрах зеркал рекомендуется выполнить калибровку через сервисное меню или диагностический сканер.
