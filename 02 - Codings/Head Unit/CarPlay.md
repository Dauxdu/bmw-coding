# CarPlay

> [!WARNING] Совместимость
> Активация требует:
>
> - Поддержки на уровне железа (наличие WiFi-модуля)
> - Совместимой версии прошивки HU
> - iPhone с iOS 13+

> [!INFO] Блок управления
> **HU_NBT**, **HU_NBT EVO**, **MGU** — в зависимости от поколения

---

## Базовая активация

```
Блок: [соответствующий]
Параметры:
- CARPLAY → aktiv
- SMARTPHONE_CONNECTIVITY → aktiv
- WIFI_HOTSPOT → aktiv (для беспроводного CarPlay)
```

> [!NOTE] Проводной или беспроводной
>
> - Проводной: требует только активации параметра
> - Беспроводной: требует наличия WiFi-модуля и дополнительной настройки

---

## Переключение между источниками

```
Блок: HU_***
Параметр: SOURCE_SWITCHING_MODE → auto || manual
```

> [!TIP] Рекомендации
>
> - `auto` — автоматическое переключение при подключении телефона
> - `manual` — ручное переключение через меню Media

---

## Интеграция с мультимедиа

```
Блок: HU_***
Параметры:
- CARPLAY_AUDIO_PRIORITY → aktiv
- CARPLAY_NAVIGATION_AUDIO → ducking (снижение громкости музыки при подсказках)
- CARPLAY_SIRI_SHORTCUTS → aktiv
```

---

## Настройки приватности

```
Блок: HU_***
Параметры:
- CARPLAY_CONTACTS_SYNC → aktiv/nicht_aktiv
- CARPLAY_LOCATION_SHARING → aktiv/nicht_aktiv
- CARPLAY_ANALYTICS → nicht_aktiv (по желанию)
```

---

## Troubleshooting

| Проблема                 | Решение                                                    |
| ------------------------ | ---------------------------------------------------------- |
| CarPlay не подключается  | Проверить кабель, параметр активации, версию iOS           |
| Беспроводной не работает | Убедиться в наличии WiFi-модуля, активировать WIFI_HOTSPOT |
| Нет звука / прерывания   | Проверить AUDIO_PRIORITY, перезагрузить ГУ и телефон       |
| Ошибка в блоке           | Сбросить настройки подключения, обновить прошивку ГУ       |

---

> [!NOTE] Первое подключение
>
> 1. Подключить iPhone кабелем к USB-порту с иконкой смартфона
> 2. Разрешить доступ на экране телефона
> 3. Дождаться появления иконки CarPlay в меню Media
> 4. Для беспроводного: после первого подключения отключить кабель

---

> [!WARNING] Обновления
> После обновления прошивки головного устройства параметры активации могут сброситься. Сохраняйте резервную копию кодировок.
