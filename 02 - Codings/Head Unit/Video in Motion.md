# Video in Motion

> [!INFO] Блоки управления
> **HU_NBT**, **HU_CIC**, **HU_ENTRYEVO** — в зависимости от поколения мультимедиа

---

## Базовая разблокировка видео на ходу

### Для всех головных устройств

```
Блок: HU_*** (NBT/CIC/ENTRYEVO)
Параметры:
- SPEEDLOCK_X_KMH_MIN → FF
- SPEEDLOCK_X_KMH_MAX → FF
```

### Специфичные для HU_NBT

```
Блок: HU_NBT
Параметры:
- VIDEO_HANDBRAKE → nicht_aktiv
- VIDEO_FRONT_LOCKED → nicht_aktiv
- VIDEO_SPEEDLOCK_CONDITION → none
- SPEEDLOCK_FREISCHALTMENU → aktiv
```

### Для HU_CIC

```
Блок: HU_CIC → 3000
Параметр: VIDEO_NUR_MIT_HANDBREMSE → nicht_aktiv
```

---

## Альтернативный метод через меню (NBT)

> [!NOTE] Требует
> Предварительной активации `SPEEDLOCK_FREISCHALTMENU → aktiv`

```
1. Толкнуть шайбу iDrive вверх (удерживать)
2. Перейти: Media → Menu → Media → CD/MM
3. Deactivate Speedlock → Yes
```

---

## Дополнительные настройки

### Отключение предупреждения о безопасности

```
Блок: HU_NBT
Параметр: VIDEO_SAFETY_WARNING → nicht_aktiv
```

### Автозапуск видео при подключении USB

```
Блок: HU_NBT
Параметр: USB_VIDEO_AUTOPLAY → aktiv
```

---

## Troubleshooting

| Проблема                         | Решение                                                         |
| -------------------------------- | --------------------------------------------------------------- |
| Видео всё ещё блокируется        | Проверить все параметры SPEEDLOCK, перезагрузить ГУ             |
| Чёрный экран при воспроизведении | Проверить формат видео, кодек, разрешение                       |
| Ошибка в блоке                   | Вернуть исходные значения, проверить совместимость версии E-Sys |

---

> [!WARNING] Важно
> После кодирования протестируйте воспроизведение видео:
>
> 1. На стоянке (проверка базовой работы)
> 2. На низкой скорости (проверка разблокировки)
> 3. С разными форматами файлов (проверка кодеков)
