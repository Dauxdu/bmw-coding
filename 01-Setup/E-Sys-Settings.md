## Настройки программы

```
Settings → Options → Update VCM... → OFF
Settings → Options → Update MSM... → OFF
```

---

## Дополнительные рекомендации

### Пути к данным

```
Options → Paths:
- Data Directory: C:\EC-Apps\ESys\data\
- Project Directory: C:\EC-Apps\ESys\projects\
```

### Язык интерфейса

```
Options → Language → English (рекомендуется)
```

### Резервное копирование

```
Перед кодированием:
1. Считать FA автомобиля
2. Сохранить оригинальные параметры (Read Coding)
3. Экспортировать текущую конфигурацию
```

---

## Решение проблем

| Проблема           | Решение                                        |
| ------------------ | ---------------------------------------------- |
| Не видит машину    | Проверить ENET, зажигание, подождать 30 сек    |
| Ошибка подключения | Перезапустить E-Sys, переподключить кабель     |
| Блокировка функций | Проверить статус зажигания, уровень заряда АКБ |

> [!TIP] Совет
> Всегда подключайте зарядное устройство к АКБ при длительных сессиях кодирования!
