# E-Sys Settings

> [!IMPORTANT]
> **E-Sys / E-Sys Launcher Pro** — основное ПО для FDL/VO-кодирования
> BMW F/G серий.

---

## Обязательные настройки

```text
Settings → Options → Update VCM... → OFF
Settings → Options → Update MSM... → OFF
```

> [!NOTE]
> Отключение обновлений VCM/MSM предотвращает случайную перезапись
> конфигурации автомобиля при подключении.

---

## Пути к данным

```text
Options → Paths:
- Data Directory:    C:\EC-Apps\ESys\data\
- Project Directory: C:\EC-Apps\ESys\projects\
```

---

## Язык интерфейса

```text
Options → Language → English
```

> [!NOTE]
> Английский интерфейс рекомендуется для единообразия с документацией
> и названиями параметров в E-Sys.

---

## Резервное копирование перед кодированием

```text
1. Считать FA автомобиля (Read FA)
2. Сохранить оригинальные параметры (Read Coding → Save)
3. Экспортировать текущую конфигурацию SVT
```

---

## Замечания и важные моменты (Troubleshooting)

| Проблема / Ошибка  | Как проверить настройку / Решение           |
| :----------------- | :------------------------------------------ |
| Не видит машину    | Проверить ENET, зажигание, подождать 30 сек |
| Ошибка подключения | Перезапустить E-Sys, переподключить кабель  |
| Неверные пути      | Указать вручную Data/Project Directory      |

---

> [!WARNING]
> Всегда подключайте зарядное устройство к АКБ при длительных сессиях
> кодирования. Падение напряжения ниже 12 В может повредить блоки.
