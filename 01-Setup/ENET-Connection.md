# ENET Connection

> [!WARNING]
> Не отключайте кабель во время чтения/записи данных — возможна ошибка блока!

---

## Порядок подключения

1. **Включить зажигание** или завести автомобиль
2. **Подождать до 30 секунд** (инициализация шин)
3. **Подключить OBD-разъём** к автомобилю
4. **Подождать до 30 секунд** (определение интерфейса)
5. **Подключить ENET к ноутбуку**

---

## Troubleshooting

### Не подключается

```
1. Проверить кабель ENET (исправность, плотность подключения)
2. Убедиться, что зажигание включено
3. Перезапустить E-Sys
4. Проверить драйверы Ethernet-адаптера
5. Отключить антивирус/брандмауэр на время подключения
```

### Ошибка "No response from ECUs"

```
1. Подождать ещё 30-60 секунд
2. Выключить/включить зажигание
3. Проверить уровень заряда АКБ (>12.5V)
4. Попробовать другой порт USB
```

### Частые разрывы связи

```
1. Использовать качественный ENET-кабель
2. Избегать перегибов кабеля
3. Подключить ноутбук к сети (не от батареи)
4. Отключить энергосбережение USB в Windows
```

## Быстрые команды

```
Connection → Connect (F3)
Connection → Disconnect (F4)
Read Coding (F5)
Write Coding (F6)
```

> [!NOTE]
> Некоторые функции доступны только при заведённом двигателе.
